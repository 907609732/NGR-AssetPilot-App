# API 配置说明（Windows 桌面版 v3.0.24）

**正式桌面版通过软件内设置管理服务与凭据，不读取本目录的 `local-config.js`。** 本目录保留旧版兼容说明和字段示例；复制或修改这里的文件不会为 v3.0.24 安装版配置 API。

## 正确配置方式

1. 启动已安装的 NGR AssetPilot，在设置中打开 API/AI 接入或翻译服务配置。
2. 选择所需服务，按界面填写服务地址、模型和必要凭据；内置云翻译以软件当前提供的配置为准，不需要把服务端密钥写入客户端源码。
3. 使用对应的“测试 API”验证，再保存配置。使用本地知识库命名和手动命名不需要配置在线模型 API。

Windows 桌面版通过 Electron `safeStorage` / Windows DPAPI 加密保存用户凭据。保存后的密钥由主进程使用，界面读取配置状态；普通项目设置、命名记录和图片不因此变成加密数据。

## 迁移时的凭据规则

| 运行方式 | 导出行为 | 导入行为 |
| --- | --- | --- |
| Windows 桌面版 | 新导出的 `.ngrap` 不含 Windows 安全存储中的密钥，“携带加密凭据”选项禁用。 | 可导入工作区；新设备需重新配置密钥。旧版加密凭据包可用原迁移密码导入，凭据块上限为 8 MiB。 |
| 旧浏览器兼容模式 | 凭据保存在当前浏览器、当前工具地址的本地配置内；主动勾选携带凭据时，凭据块要求至少 12 位迁移密码加密。 | 自动恢复限于原站点数据；换浏览器、换地址或转入桌面版时需显式导出、导入。 |

`.ngrap` 的设置、工作区和图片内容不等于整体加密。将应用数据目录复制到另一台电脑也不能替代正确的 API 配置和迁移流程。

## 示例文件与开发约定

- `local-config.example.js` 仅说明字段格式，保留占位值即可；不把它复制为生产环境的密钥来源。
- `local-config.js` 是已忽略的历史兼容文件，不作为 V3 运行时配置来源；如保留该文件，应保持空配置。
- API Key、密钥、令牌、密码和登录资料不应提交到 Git、放入安装包或随共享工程分发。
- 自建百度 CFC 翻译服务时，百度 APPID 和密钥只配置在服务端环境变量中；桌面端只使用公开 Endpoint。

若真实凭据曾被提交或分发，需要在对应服务商撤销并轮换；仅删除当前文件不能移除历史副本。

开发最新版请使用 [v3.0.24 对应源码](https://github.com/907609732/NGR-AssetPilot-App/tree/v3.0.24)；默认分支的旧兼容文件不代表最新版安装流程。完整说明见[桌面版文档](../../README-DESKTOP.md)和[数据与安全说明](../../docs/安全性说明.md)。凭据与迁移行为可核对 [v3.0.24 迁移实现](https://github.com/907609732/NGR-AssetPilot-App/blob/v3.0.24/app/js/workspace-migration.js)。

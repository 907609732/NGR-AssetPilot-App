## 下载与安装

1. 打开上方 **Releases 下载页**，展开正式版的 **Assets**。
2. 下载 `NGR-AssetPilot-3.0.24-Setup-x64.exe`，运行安装向导并选择安装位置。
3. 安装完成后，从桌面或开始菜单打开 **NGR AssetPilot**。
4. 先用本地知识库或内置离线 AI 翻译完成一次命名；需要自有在线翻译或视觉模型时，再到 **设置 → API** 配置并测试服务。

普通用户使用 Windows x64 安装包即可，无需搭建 Node.js 开发环境。当前版本未做 Windows 代码签名，系统可能显示“未知发布者”；可用同一 Release 中的 SHA-256 文件核对下载内容。

| Release 文件 | 用途 |
| --- | --- |
| `NGR-AssetPilot-3.0.24-Setup-x64.exe` | 正式版安装器，日常使用下载这一项 |

仓库的 `Code → Download ZIP` 也用于下载源码。根目录保留的 `点击启动服务.html` 是旧浏览器兼容入口，桌面专属功能请从安装后的应用进入。

## 能做什么

| 功能 | 日常用途 |
| --- | --- |
| **批量切图命名** | 导入文件夹、单张图片和参考图，结合项目规范生成名称；支持手动编辑、批量前后缀与序号，发现同一工程目录重名时阻止误导出 |
| **多种命名服务** | 本地知识库、内置离线 AI 翻译、NGR 云翻译、自有百度翻译、OpenAI 兼容文本服务与 AI 视觉命名；按任务选择合适模式 |
| **项目方案与进度** | 管理项目、命名方案、页面／组件／状态词库和规则模板；命名记录自动保存在本机，支持列表、紧凑列表与画册 |
| **UI 切图检测** | 按当前项目方案检查 PNG 格式、尺寸、奇数宽高、大图倍数、图标规格和疑似重复资源，集中筛选问题与警告 |
| **本地 AI 搜图** | 选择本地图库并建立索引，浏览素材、粘贴截图、以图搜图或用中英文搜索；支持 DirectML、CPU 回退、离线模型包与经过验证的 ONNX 模型 |
| **基地提单表自动填** | 粘贴整月自然语言日报，在本机解析日期、S 等级和人天；核对编辑后复制表格或导出 Excel |
| **TAPD 周报／月报** | 登录后按日期采集事项，核对分类、S 等级和人天，复制周报或导出月报 Excel；可附带已提取的 Bug 图片 |
| **TAPD Bug 媒体** | 提取描述、评论和附件中的可下载图片与视频；按单号或标题浏览、查看原图、复制图片、播放视频和定位文件 |
| **快速找界面扩展** | 导入兼容扩展 ZIP 后打开独立工作台；扩展及模型单独交付 |
| **其他辅助工具** | 网络与 API 诊断、ArtHub 工程文件夹只读查询、外部应用快捷入口、防止息屏、开机启动、应用内教程与 Figma 一键变体使用指南 |

图片导出支持工程文件夹和 ZIP，保留原始图片内容，只改变导出名称。检测阈值随项目方案变化，以软件内当前“检测规范说明”为准。

## 第一次使用怎么走

### 切图命名与规范检测

在 **设置 → 命名规则** 选择项目和方案、维护词库，然后进入 **开始命名** 导入切图。选择命名服务，运行后检查推荐名和冲突提示，再导出到目标文件夹或 ZIP。需要检查提交规范时，进入 **UI 切图检测**，选择当前项目组与检测模式。

本地知识库和内置离线翻译不需要 API Key。NGR 云翻译需要联网；自有百度、OpenAI 兼容文本服务和视觉 AI 需要按 **设置 → API** 中的要求配置。视觉命名会把选用的图片和命名上下文发送给所选服务。

### 本地 AI 搜图

进入 **本地 AI 搜图**，准备搜索模型，添加图片文件夹并完成分析后，再浏览或搜索。联网电脑可按提示下载模型，离线电脑可导入 `.ngrmodel` 模型包或受支持的本地 ONNX 模型。

搜索模型与安装包内置的中译英模型用途不同，不能用“离线翻译已可用”判断搜索模型已经就绪。图像单塔模型只支持图片搜索，文字搜索需要通过校验的图文模型。源图库保持只读，删除图库索引不会删除源图片。

### TAPD 周报、月报与 Bug 媒体

此功能需要电脑已安装 **Google Chrome**，并有可访问相应项目的 TAPD 账号。

1. 从 **更多功能 → 自动生成TAPD周报** 进入报表窗口，选择周报／月报和日期范围。
2. 点击 **登录 TAPD**，在软件打开的专用 Chrome 窗口中完成登录，再点击 **抓取所选日期**。
3. 核对分类、S 等级和人天，复制周报或导出月报。
4. 需要附件时，先执行 **提取 Bug 图片和视频**；导出月报前勾选 **月报附带 Bug 图片**，再点击 **下载月报 Excel**。

月报只附带当前报表范围内已经提取的图片，放在 `Bug图片附件` 工作表；视频在 **Bug 媒体** 页浏览。旧快照不会自动补齐新字段，需重新抓取；界面显示上次采集时间。

### 快速找界面扩展

打开 **更多功能**，点击 **快速找界面** 旁的齿轮进入扩展管理，再选择 **导入扩展 ZIP**；扩展已经运行时先关闭工作台。当前登记的已验证扩展为 `0.7.0`，扩展和模型不随主安装器附带，兼容 ZIP 尚未公开下载，需单独获取。扩展项目公开的旧独立版不能作为宿主扩展导入。

v3.0.24 会复用已持久化的校验记录；首次导入、点击 **重新检查** 或检测到文件变化时执行完整校验。升级后首次打开仍可能需要等待完整检查。

## 更新与保存

正式安装版可在 **设置 → 数据与关于 → 检查更新** 查看新版本。点击 **下载更新** 后，下载完成会自动保存工作区、退出、安装并重新打开；请先完成当前正在采集或导出的任务。

命名记录和配置保存在本机。换电脑或清理资料前，可在 **数据与关于** 导出 `.ngrap` 迁移备份；新备份不导出 Windows 安全存储中的 API 密钥，换机后需要重新填写。搜图库、模型、TAPD 记录和扩展资料有各自的存储范围，详见 [数据与安全说明](docs/安全性说明.md)。关闭主窗口通常会缩到托盘，需要完全退出时使用托盘菜单的 **退出软件**。

## v3.0.24 更新重点

- **快速找界面打开更快**：持久化文件校验记录，日常打开复用，异常时重新完整检查。
- **TAPD 等级补全**：标题无 S 等级时读取详情的“修复分支”；人工调整优先于标题，标题优先于分支。
- **月报附图**：将当前范围内已提取的 Bug 图片放入 Excel 独立工作表。
- **媒体提取修复**：等待描述加载，过滤 TAPD 全局 AI 助手推广图，优先保留可下载原图。
- **采集日期更清楚**：增加“上周”“今天”快捷日期，并显示采集时间。

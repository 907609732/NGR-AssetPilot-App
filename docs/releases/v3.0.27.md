# NGR AssetPilot v3.0.27

## 首页与日常工具

- 首页采用纯色背景，鼠标移动时显示淡色光斑。左侧为命名大卡，右侧为两张工具卡，三张卡片均配有图标。
- 命名页仅在使用 AI 视觉命名时显示参考图上传与预览。工程名旁的打开文件夹入口暂时移除。
- 网络诊断新增 26 项，可单独检测一个服务，也可批量检测当前分类中勾选的服务。
- 本地搜图的模型管理新增删除确认和删除结果提示。离线时可删除或导入本地模型。

## 快速找界面与本机连接

- 快速找界面随桌面版提供，可直接从首页打开。
- 文件夹资料库与本机缓存分别管理，AI 搜图、离线翻译和媒体处理所需组件按需安装。
- 本机 MCP 可访问快速找界面、自动命名和切图检测。首页感叹号可查看接入方式或打开本机网页。

## 安装与更新

- 提供未签名的 Windows x64 安装器和 SHA-256 校验文件。Windows 可能显示未知发布者提示。

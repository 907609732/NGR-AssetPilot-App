# NGR AssetPilot V3.0.7 正式版

本版本修复 Windows 资源管理器中的文件夹无法直接拖入“上传切图”和“UI 切图检测”区域的问题。

## 文件夹拖入修复

- 拖入文件夹时同步保留 Chromium 目录入口和标准文件系统句柄，避免异步等待后丢失目录访问能力。
- Electron 桌面版优先使用与 Windows 原生拖放绑定的 Chromium 目录入口，递归读取子文件夹并保留相对路径。
- Chromium 目录入口不可用时自动回退到标准 File System Access 句柄；句柄权限或遍历失败不会再中断整次导入。
- 普通图片、多个图片和“选择文件夹”入口保持原有行为。

## 质量与发布

- 增加目录入口优先、目录句柄后备、异步拒绝处理和嵌套相对路径测试。
- 完整自动化测试通过后重新构建正式安装包、便携版、自动更新元数据、SBOM 和 SHA-256 校验清单。
- V3.0.6 正式安装版可通过软件内置更新升级到 V3.0.7。

## 已知说明

- 安装包当前未使用 Authenticode 证书签名，Windows 可能显示 SmartScreen 提示；请只从本项目 GitHub Releases 下载并核对 SHA-256。

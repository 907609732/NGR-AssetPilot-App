# NGR AssetPilot v3.0.24

发布日期：2026-11-04

适用产品：Windows x64 正式安装版

[GitHub Release 与安装附件](https://github.com/907609732/NGR-AssetPilot-App/releases/tag/v3.0.24)

本版优化快速找界面扩展的打开速度，并汇总此前尚未公开发布的 TAPD 周报、月报与媒体修复。

## 快速找界面

- 日常打开复用持久校验记录，检查文件是否变化，不再每次完整读取约 799 MB 的扩展文件。
- 首次导入、点击“重新检查”时完整校验；发现文件变化、记录缺失或损坏时也会完整检查。
- 校验记录跨软件重启保留。旧安装升级后首次打开需完整检查一次，之后自动复用。
- 保留缺失文件、额外文件、目录联接和内容损坏的检查，项目、模型与工作台功能保持原样。

## TAPD 周报、月报与媒体

- 修复标题没有 S 等级时读取详情页“修复分支”的异步时序，例如 `Trunk_S2` 识别为 S2；标题等级和人工调整优先。
- 导出月报 Excel 可附带当前报表范围内已提取的 Bug 图片，图片置于独立工作表，原月报表格保持原样。
- 提取媒体时等待描述内容加载，过滤 TAPD 全局 AI 助手推广图，解决每个单子都混入同一张推广图的问题。
- 描述图片优先保留可下载原图；图片放大和复制使用完整图片，视频继续在 Bug 媒体中浏览。
- 新增“上周”“今天”快捷日期，展示报表采集时间，避免将旧快照误认为最新数据。历史快照需重新采集才会补充详情字段。

## 开发与安装

- 源码开发版支持双击“打开或重启”直接验证修改；正式发布时再打包。
- 提供 Windows x64 Setup 安装器、SHA-256、SBOM、构建清单及自动更新元数据。
- 沿用未签名构建方式，Windows 安装时可能显示“未知发布者”。

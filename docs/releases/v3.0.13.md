# NGR AssetPilot v3.0.13

- 恢复开箱即用的 NGR 云翻译，客户端不需要填写 Token 或百度密钥。
- 云端 HTTP 触发器改为“不验证”，百度密钥仅保留在云函数环境变量。
- 每来源 IP 滚动半小时最多 1000 次请求，单次最多 200 字符；计数在单个函数实例内，多实例不共享，重启会清空。
- 修复 Windows 生成云函数 ZIP 时的 Linux 文件权限，避免部署后入口文件无法读取。
- 保留离线翻译以及默认关闭、自动保存设置的防止息屏功能。

本版本延续已确认的未签名 Windows 正式版发布方式，安装时可能显示未知发布者。提供 SHA-256 校验文件及自动更新元数据。

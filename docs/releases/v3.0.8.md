# NGR AssetPilot V3.0.8 正式版

本版本补齐离线中译英、百度翻译 API、可自定义外部应用启动器，并把在线服务配置统一收口到“设置 → API”。

## 内置离线翻译

- 安装包内置固定 revision 的 `Xenova/opus-mt-zh-en` 量化 ONNX 模型，安装后中文文件名翻译无需联网或 API Key。
- 模型在隔离 Worker 中按需加载，运行时禁止远程模型访问；文字和图片不会因离线翻译上传。
- 词库与拼音继续作为自动兜底；翻译输入框支持按 Enter 直接生成命名词。
- 模型文件使用固定大小和 SHA-256 清单校验，并在发布包中附带第三方模型来源与 CC BY 4.0 许可说明。

## API 与翻译配置

- 接入百度翻译新版 API Key 与传统 App ID + 密钥两种鉴权，并用于批量命名和浮动翻译工具。
- 新增统一“API”设置页签，集中管理视觉命名、百度翻译和 OpenAI 兼容文本模型。
- 命名规则页和浮动翻译窗口不再重复显示地址、模型或密钥表单。
- 用户输入的新密钥只在保存过程中短暂经过渲染层与受限 IPC；已保存或解密后的密钥由主进程通过 Windows DPAPI 管理，不会返回渲染层，也不进入本地日志、迁移包或公开安装包。

## 外部应用快捷启动

- 命名工作区新增受控的外部应用启动器，默认识别 ArtHub，完成命名后可直接拉起上传工具。
- 可在本机选择、登记和移除其他 Windows 应用；渲染层只使用注册 ID，不能提交任意可执行路径。

## 质量与发布

- 覆盖离线模型清单、真实 ONNX 推理、统一 API 页、百度鉴权、外部应用注册、IPC 边界和 Electron UI 流程。
- 正式安装包包含自动更新所需的 `latest.yml` 与 blockmap，并附带 SHA-256、CycloneDX SBOM 和构建清单。
- V3.0.7 正式安装版可通过软件内置更新升级到 V3.0.8。

## 已知说明

- 正式 Release 不包含任何共享百度密钥；需要在线百度翻译时，请在“设置 → API”保存自己的凭据。内置离线翻译开箱即用。
- 安装包当前未使用 Authenticode 证书签名，Windows 可能显示 SmartScreen 提示；请只从本项目 GitHub Releases 下载并核对 SHA-256。

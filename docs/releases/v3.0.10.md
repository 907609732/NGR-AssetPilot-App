# NGR AssetPilot V3.0.10 正式版

本版本为所有用户提供开箱即用的百度在线翻译，同时保留离线翻译和用户自有凭据模式。

## 开箱即用翻译

- 正式版默认启用由 NGR 托管的百度 CFC 翻译服务，无需用户填写 APP ID 或密钥。
- 首次启动自动选择可用的托管翻译提供者；现有用户的自定义选择保持不变。
- 翻译请求由桌面主进程发送，渲染页面无法读取云端访问 Token。

## 安全与稳定性

- 百度 APP ID 与密钥仅保存在百度 CFC 环境变量，不进入源码、Git 历史或安装包。
- CFC 入口使用 HTTPS 与 Bearer 鉴权，正式构建从受保护的 GitHub Environment 注入托管配置。
- 托管地址只允许固定的百度 CFC HTTPS 域名和路径，配置异常时安全回退，不暴露敏感信息。
- 输入继续限制为 200 字符，并保留离线翻译作为无网络环境下的兜底方案。

## 验证

- 云端健康检查、未授权请求拒绝和真实中译英请求均已通过。
- 完整自动化测试通过；正式安装包仍为未签名版本，Windows 可能显示发布者未知提示。

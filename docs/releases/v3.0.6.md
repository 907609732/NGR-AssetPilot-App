# NGR AssetPilot V3.0.6 正式版

本版本重点完善本地 AI 搜图的素材浏览、GPU 索引一致性、离线模型管理和桌面端可靠性，并补齐严格的 PNG 切图检测。

## 本地 AI 搜图与素材库

- 未发起搜索时默认进入素材库模式，可按文件夹树浏览已分析图片。
- 提供每页 100 张的分页网格、快速图库切换、名称与路径筛选，以及路径、修改时间、大小排序。
- 支持懒加载缩略图、打开原图和在资源管理器中定位；素材库始终保持源目录只读。
- 清空图片或文字查询后返回素材库；零结果与搜索错误保持独立状态。
- 新默认视觉模型升级为固定版本的 q4f16 ONNX，兼顾 DirectML 批量分析速度与 CPU/GPU 检索一致性。
- 保留旧模型和旧索引为兼容模式；模型、执行设备或驱动配置变化时使用隔离索引，避免不同向量混写。

## 稳定性与安全性

- 图库扫描、推理和索引发布改为两阶段提交；取消、目录失联、权限错误或进程退出不会破坏上一次可用索引。
- 索引、查询和状态任务使用隔离进程，并补充超时、异常退出恢复和向量缓存内存上限。
- 自定义 AI 服务由主进程统一管理地址和凭据，渲染层不能读取已保存的 API Key，并支持真实请求取消。
- 工作区备份改为流式导入导出，增加路径、条目数、单项大小、总大小和哈希校验，并继续兼容 `.ngrap` v1。
- 本地日志只记录脱敏后的操作阶段和错误码，不记录密钥、搜索文字、图片内容或完整路径。

## 切图检测与工程质量

- 切图检测现在仅接受扩展名和文件签名都正确的 PNG；JPEG、WebP、GIF、SVG、BMP、TIFF、AVIF、伪装 PNG 和损坏文件都会明确报错。
- 更新数据库迁移、素材分页索引、模型断点续传、自动更新元数据和发布供应链检查。
- 增加素材库、模型、GPU、扫描恢复、流式备份、Provider 网络、更新界面和 PNG 格式检测回归测试。

## 升级说明

- V3.0.5 正式安装版可通过软件内置更新升级到 V3.0.6。
- 模型不包含在安装包中；联网电脑可按需下载，纯离线电脑可从模型管理器导入本地模型包或受支持的 ONNX embedding 模型。
- 安装包当前未使用 Authenticode 证书签名，Windows 可能显示 SmartScreen 提示；请只从本项目 GitHub Releases 下载并核对 SHA-256。

# NGR AssetPilot v3.0.12

- 设置新增「防止息屏」，首次安装默认关闭，手动开启后自动保存，重新启动软件恢复。
- 提供系统保活、鼠标微动及双重保活模式。鼠标仅在空闲时约每 30 秒交替微移，操作时暂停。
- 软件最小化后继续保活，退出后停止；锁屏或休眠期间暂停，返回后恢复。
- 设置页展示运行或失败状态，后台定期检查并尝试恢复失败的保活机制。

鼠标位移受 Windows 指针设置影响，不能保证完全不可见。该功能不覆盖手动锁屏或系统强制休眠策略。

本版本为未签名的 Windows 正式版，安装时 Windows 可能显示未知发布者提示。提供 SHA-256 校验文件及自动更新元数据。

云翻译接口暂不可用，本版本不内置其配置，可使用离线翻译或自行配置服务。新增统一 API 设置页和网络诊断入口，支持查看网络连通性、管理自定义诊断目标和本地诊断历史。

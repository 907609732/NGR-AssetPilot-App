# NGR AssetPilot v3.0.16

本版本把 TAPD 周报／月报工具正式集成到 NGR AssetPilot，并修正周报日期重复、分组工时拆散等问题。

## TAPD 周报／月报

- 首页底部新增“TAPD 月报”入口，不影响主要的命名、切图和本地搜图功能。
- 使用独立 TAPD 登录窗口，支持按本周、月份或日期范围抓取“我的工作 → 已办”事项。
- 可在软件内确认或修改 S 等级与分类，核对完成后复制周报或下载月报 Excel。
- 月报 Excel 保持固定 12 列提单格式、真实日期和数值人天，并使用新的文件保存路径，不修改原始样本。

## 周报格式修正

- 周报改为严格按日期汇总，每天只输出一次“日期 + 等级 + 总人天”标题。
- 当天全部事项逐行排列在日期标题下方，不再因不同等级重复日期，也不会把每日 1 人天拆成多个标题。
- 同一天确有多个等级时合并显示，例如 `S1/S2`，避免遗漏等级信息。
- 周报预览、纯文本复制、单列表格复制、TXT 和 Markdown 导出使用同一套格式。

## 数据清理与桌面体验

- TAPD 报表工具新增红色“清除所有数据”按钮，并使用系统原生二次确认框。
- 清理范围包括采集快照、分类与等级调整、人天分配和导出历史；不会退出 TAPD，也不会删除已经导出的文件。
- 主窗口关闭后缩到 Windows 托盘，后台任务可继续运行；可从托盘或再次启动软件恢复窗口并明确退出。

## 隐私、安全与发布

- TAPD 登录状态、采集快照和人工调整只保存在本机；报表内容不上传大模型。
- TAPD 子窗口继续使用独立预加载脚本、受限 IPC、可信来源校验和本地 SQLite 存储。
- v3.0.15 正式安装版可通过软件内更新升级到 v3.0.16。
- 正式安装包包含 `latest.yml` 与 blockmap，并附带 SHA-256、CycloneDX SBOM 和构建清单。
- 当前生产环境尚未配置受信任的 Windows 代码签名证书，本版本延续未签名发布方式；安装时 Windows 可能显示“未知发布者”提示。

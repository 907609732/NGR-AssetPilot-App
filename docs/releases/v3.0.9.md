# NGR AssetPilot V3.0.9 正式版

本版本把在线翻译接入升级为可直接使用百度 CFC 账号，并补齐桌面运行时的完整流程。

## 百度翻译 CFC

- 新增翻译服务选项：`baidu`（传统接口）与 `cfc`（百度 CFC）共用统一接口能力。
- 当选择 CFC 时，服务由 `baidu-cfc` 提供者承载，支持 App ID + 传统密钥或新版 API Key 模式。
- 桌面运行时不在渲染层持久化明文密钥；配置同步到安全存储后，页面只保留状态标记。

## 稳定性与交互

- 恢复/加载桌面已保存凭据时，兼容 CFC 的 `providerId` 与端点回填。
- 清空/切换翻译服务后，表单联动逻辑和字段显示保持一致。
- 翻译相关测试补充了 CFC provider 解析与 UI 选项校验。

## 已知说明

- CFC 仍沿用现有的内置离线翻译兜底机制；未配置在线服务时优先走离线能力。

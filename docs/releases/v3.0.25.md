## Figma 插件健康检测

- 在“更多功能”新增“Figma插件健康检测”。
- 检查 service.arthub.qq.com、service.arthub.woa.com、localhost:31700、api.figma.com 和 www.figma.com。
- 逐项显示响应状态、耗时和标准错误码，支持取消和重新检测。
- 任一网络连接失败或服务返回 5xx 时，立即显示网络限制提示，其余检测继续执行。
- 401/403 单独显示需要登录或鉴权。本机 31700 端口直接检查本机服务。
- 检测提示根据当前连通结果生成，实际原因可能包括本机 ArtHub 服务未启动、内网不可达或网络限制。

# NGR AssetPilot V3.0.4 正式版

本版本完成“本地 AI 搜图”的 GPU 加速与离线多模型支持，并修复大图库分析速度会随索引数量持续下降的问题。

## 主要更新

- Windows 图库批量分析使用 ONNX Runtime DirectML，自动探测显卡并在失败时安全回退 CPU；无需安装 CUDA、Python或额外显卡开发环境。
- 索引流水线采用批量 16、单请求双缓冲、8 路有界预处理和每 256 条事务提交；界面显示真实执行设备、批量大小、图片/秒和预计剩余时间。
- 修复 SQLite 重复内容查询的 O(n²) 执行计划，固定先走 `(library_id, sha256)` 内容索引。
- 新增离线模型管理器，可导入图像单塔或图文双塔 ONNX embedding 模型；模型文件、tokenizer、输入输出、预处理和向量维度均在隔离进程中校验。
- 不同模型的向量索引相互隔离；切换模型不会覆盖旧索引，删除模型或图库不会删除源图片。
- 正式安装版补齐 `latest.yml`、安装包和 blockmap 的发布链路，供软件内置更新检查使用。

## 实机验收

- 测试电脑：Windows 11、RTX 3080 Ti。
- XDProject：27,640 张可分析图片，源文件总目录约 4.9 GB。
- 首次完整分析：222.72 秒（约 3 分 43 秒），整体 124.1 张/秒，0 错误。
- 无变化增量重扫：7.71 秒，27,640 张全部复用。
- 源图库的文件数量、大小和修改时间哈希在测试前后完全一致。

## 升级说明

- V3.0.4 使用新的批量索引配置。首次升级会保留图片路径、SHA-256、尺寸等元数据，但内置模型的旧版单张 CPU 向量需要重新分析，避免 CPU/GPU 向量静默混用。
- 内置量化模型优先保证速度，同图在本机验证 Top 5 命中为 100%，但不承诺严格的跨设备排序一致性。对此有硬性要求时，请导入经验证的 FP16/FP32 embedding 模型并建立独立索引。
- 如果仍在 V3.0.2 或更早版本且没有收到应用内更新提示，请手动安装一次 V3.0.4；后续正式安装版将继续使用内置更新通道。

模型不包含在安装包中。联网电脑可首次按需下载；纯离线电脑可在模型管理器中导入 `.ngrmodel` 包或经过验证的本地 ONNX embedding 模型。

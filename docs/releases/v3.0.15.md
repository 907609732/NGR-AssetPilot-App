# NGR AssetPilot v3.0.15

本版本新增“基地提单表自动填”，用于把整月自然语言日报快速整理成可浏览、可修改并可直接交付的 Excel 提单表。

## 基地提单表自动填

- 粘贴整月任务后，自动识别日期、日期范围、S1/S2/S3、工作量和续行任务。
- 每条任务独立生成一行；同一日期组存在多项任务时平均拆分人天，并精确分配两位小数余数。
- 在软件内按分类、等级、日期和关键词浏览，支持逐格修改、删除任务和重新平均分配工时。
- 对无日期任务、非法日期、缺失或非正工作量、声明合计不一致等问题进行明确提示；修正前禁止复制和导出。
- 自动保存当前草稿和常用默认值；“清除所有数据”只清空本次原文、表格和筛选，保留常用提单默认值。

## 复制与 Excel 导出

- “复制表格”输出包含表头的 12 列 TSV，可直接粘贴到 Excel 或 WPS。
- “导出 Excel”生成新的 `.xlsx` 文件，不读取、覆盖或修改历史样本。
- 工作表保持 `Sheet1`，日期为真实 Excel 日期、工作量为数值；默认行高 80 磅，第一行无底色。
- 工作量使用通用数值格式，在 WPS 中正确显示 `1`、`0.5`、`0.34`，不会出现整数后的多余小数点。
- 默认列宽和提单字段取自 8 月及更早的完整样本；不完整的 9 月样本仅用于解析回归。

## 隐私、安全与兼容性

- 日报内容全程在本机解析，不调用大模型、不上传网络。
- 渲染层只提交已校验的结构化行；主进程负责保存对话框和 Excel 生成，不开放 Node.js 或完整文件系统能力。
- IPC 继续限制行数、单元格长度、日期和数值，并在主进程重新校验。
- 已验证完整 9 月样本可得到 27 行、21 个日期组和 22 人天；ExcelJS 回读、WPS 实际打开及 Electron 可见界面流程均通过。

## 发布与升级

- v3.0.14 正式安装版可通过软件内更新升级到 v3.0.15。
- 正式安装包包含 `latest.yml` 与 blockmap，并附带 SHA-256、CycloneDX SBOM 和构建清单。
- 当前 GitHub 生产环境尚未配置受信任的 Windows 代码签名证书，本版本延续此前未签名发布方式；安装时 Windows 可能显示“未知发布者”提示。
- 正式构建继续执行生产依赖审计、凭据扫描、IPC 边界测试、真实 Electron 界面测试和打包应用启动验证。

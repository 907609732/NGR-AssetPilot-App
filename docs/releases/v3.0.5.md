# NGR AssetPilot V3.0.5 正式版

本版本将正式安装包升级为可选择安装目录的辅助安装向导，并完整包含 V3.0.4 的本地 AI 搜图 GPU 加速、离线多模型和自动更新修复。

## 主要更新

- 用户手动运行 Setup 安装包时显示安装向导，可以选择安装目录。
- 保持安装器 GUID 和应用 ID 不变；手动安装默认采用当前用户范围且不自动请求管理员权限，软件内确认更新后仍静默覆盖原安装目录，不弹出路径选择页。
- 自定义安装路径不会改变 `%APPDATA%\NGR AssetPilot` 中的设置、图库索引、模型和缩略图位置。
- 应用版本、界面版本标识和静态资源缓存版本统一升级为 V3.0.5。

## 本地 AI 搜图

- Windows 图库批量分析继续使用 ONNX Runtime DirectML，并在不兼容或显存不足时安全回退 CPU。
- 支持完全离线导入图像单塔或图文双塔 ONNX embedding 模型。
- 图库、模型指纹与执行配置继续使用相互隔离的向量索引；删除索引、图库或模型不会删除源图片。

## 构建验证

- 完整自动化测试与打包产物检查：58 项全部通过，无失败或跳过。
- 正式版安装包按辅助向导模式生成，打包应用启动验证通过。
- `latest.yml`、安装包、blockmap、SHA-256、SBOM 和构建清单均由发布流程重新生成并校验。

## 升级说明

- V3.0.4 正式安装版可以通过软件内置更新升级到 V3.0.5。
- 如果仍在 V3.0.2 或更早版本且没有收到更新提示，请手动下载安装一次 V3.0.5。
- 安装包当前未使用 Authenticode 证书签名，Windows 可能显示 SmartScreen 提示；请从本项目 GitHub Releases 下载并核对 SHA-256。

模型不包含在安装包中。联网电脑可首次按需下载；纯离线电脑可在模型管理器中导入 `.ngrmodel` 包或经过验证的本地 ONNX embedding 模型。

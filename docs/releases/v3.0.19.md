# NGR AssetPilot v3.0.19

本版本完善 TAPD 周报正文：每条事项显示自己的 S 等级，并可选择附加日期与人天。

## TAPD 周报正文

- 保留每天原有的“日期 + S 等级 + 总人天”汇总标题。
- 每条正文前固定显示该事项自己的 S 等级，混合等级的任务也能逐条区分。
- 周报预览新增“日期”“人天”两个勾选框，默认均不勾选，自动保存选择。
- 勾选后立即更新预览；复制纯文本、复制单列表格、TXT 和 Markdown 导出均采用相同格式。
- 正文人天使用该事项当天的分配量，跨日合并任务不会重复显示整项总人天。
- 月报 Excel 和原始清单 CSV 保持原有格式。

## 安装与更新

- 支持通过软件内检查更新升级，保留已有数据和 TAPD 登录状态。
- 提供 Windows x64 安装包、自动更新清单、blockmap、SHA-256、SBOM 和构建清单。
- 沿用现有未签名发布方式，Windows 安装时可能显示“未知发布者”。

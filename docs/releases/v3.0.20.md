# NGR AssetPilot v3.0.20

本版本扩展 TAPD Bug 单媒体提取和浏览功能。

## TAPD Bug 媒体

- “提取 Bug 图片和视频”可读取描述、评论和附件中的图片与 MP4/WebM 视频，按 Bug 单号保存。
- 同时处理最多 2 张详情页、4 个下载任务；停止时保留已完成文件及提取清单。
- 新增“Bug 媒体”页签，可按单号或标题搜索、查看原图、复制图片、播放视频和定位文件。
- 描述中的图片优先使用 TAPD 提供的原图地址；列表预览会缩小显示，放大和复制使用保存的完整图片。
- 兼容已有图片导出目录；视频按需加载并支持拖动播放进度。
- 过滤头像、代码与压缩包附件，并限制下载大小和可访问地址。

## 本地验收

- 指定的真实 TAPD Bug 单提取 5 张图片、2 段视频，0 失败；两段视频均在软件内播放，原图复制与源文件像素一致。
- 旧周报的 6 张 Bug 单提取 23 张图片、1 段视频，0 失败。

## 安装

- Windows x64 正式版安装包；构建过程生成 SHA-256、SBOM 和更新清单。
- 沿用已授权的未签名构建方式，安装时 Windows 可能显示“未知发布者”。

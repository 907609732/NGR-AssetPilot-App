# NGR AssetPilot v3.0.23

本版汇总 TAPD 周报、月报和 Bug 媒体功能的后续改进。

## TAPD 周报与月报

- 日期栏新增“上周”和“今天”快捷选择；“上周”按周一至周日计算。
- 周报正文继续逐条显示 S 等级，日期和人天由两个独立选项控制。
- Bug 标题没有 S 等级时，采集器尝试读取详情页“修复分支”字段，例如 `Trunk_S2` 识别为 S2；标题等级和人工调整优先。
- 导出月报 Excel 时可勾选“包含 Bug 图片附件”，将当前报表范围内已提取的完整 Bug 图片放入独立工作表；视频继续在“Bug 媒体”页浏览。原月报表格保持原样。

## Bug 媒体与文档

- TAPD 描述中的图片优先提取可下载原图；列表预览缩小显示，放大和复制使用保存的完整图片。
- 项目功能和架构说明合并到根目录 `README.md` 与 `docs/ARCHITECTURE.md`；历史文档保留在 Git 历史中。

## 安装

- Windows x64 正式版 Setup 安装包，附 SHA-256、SBOM、构建清单和自动更新元数据。
- 沿用已授权的未签名构建方式，Windows 安装时可能显示“未知发布者”。

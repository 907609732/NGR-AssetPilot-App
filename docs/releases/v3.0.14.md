# NGR AssetPilot v3.0.14

本版本集中优化图片命名、切图检测、词库、更新和设置体验，并新增可在正式页面查看的完整功能测试样本。

## 命名与批量处理

- 多选图片后显示固定批量工具栏，可统一设置前缀名、工程名和界面名，并在页面底部直接删除选中图片。
- 紧凑命名顶部工具栏，让“只看问题图片”和“删除选中图片”与其他操作保持同一行。
- 图片列表使用更明显的交替底色，尺寸错误、风险图片、重名和命名失败拥有独立状态颜色。
- 命名服务改为绿色主按钮与设置图标组合，减少运行命名所需点击次数。
- 下载命名结果使用主按钮与设置入口组合，保留用户的下载方式选择。

## 词库与翻译

- 词库从图片行内移动到左侧固定入口，使用分类面板展示英文词条、中文释义和中文别名。
- 支持中英文搜索、完整词库索引、分批加载、当前图片联动、词条追加与再次点击移除。
- 词库和翻译入口使用高亮光环与玻璃面板；翻译窗口按实际内容收紧，词库窗口靠上显示以保留下方图片视野。
- 两个面板互斥打开，支持 Esc、键盘焦点、减少动态效果和小窗口布局。

## 切图检测与功能测试

- 检测列表支持勾选、全选筛选结果、固定底部删除条，以及更加清晰的逐行状态颜色。
- 设置新增“功能测试”，实时显示运行环境、命名服务、项目方案和检测状态。
- 测试完成后仍停留在测试页，并在正式“开始命名”和“UI 切图检测”页面生成隔离测试数据，由用户自行进入查看。
- 内置 53 张命名样本和 33 张检测样本，覆盖正常、警告、尺寸错误、重名、命名失败、大图、标准与异常背景图、PC/移动端效果图，以及 PNG、JPG、JPEG、WebP、GIF、SVG、BMP、TIFF、ICO、AVIF、HEIC 等格式。
- 测试数据可按正式流程筛选、编辑和批量操作；清除测试后恢复真实数据，测试修改不会写入真实命名进度。

## 设置、教程与更新

- 设置新增开机自启动，首次安装默认关闭，用户开启后由 Windows 当前用户启动项管理。
- 设置和更新弹窗展示完整历史版本；下载进度与安装操作固定在弹窗底部。
- 顶部“教程”和问号合并为“使用教程”，在软件内按当前版本讲解全部功能并支持搜索和页面直达。
- 外部应用按钮显示软件图标，自定义应用同样读取图标。
- 当前工程名旁新增 ArtHub 文件夹查询入口；查询结果保留资源库和完整路径。客户端精确定位协议尚未验证时会明确提示，不猜测协议或跳转浏览器。

## 发布与升级

- 正式安装包包含自动更新所需的 `latest.yml` 与 blockmap，并附带 SHA-256、CycloneDX SBOM 和构建清单。
- v3.0.13 正式安装版可通过软件内更新升级到 v3.0.14。
- 当前 GitHub 生产环境尚未配置受信任的 Windows 代码签名证书，本版本延续 v3.0.13 的未签名发布方式；安装时 Windows 可能显示发布者提示。
- 正式构建继续执行凭据扫描、桌面 IPC 边界检查、真实 Electron 界面测试和打包应用启动验证。

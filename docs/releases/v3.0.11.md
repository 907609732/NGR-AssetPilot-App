# NGR AssetPilot V3.0.11 正式版

本版本补齐命名翻译服务选择、全局快捷应用入口和切图检测高级配置，重点提升日常素材处理效率与项目规则适配能力。

## 命名翻译服务

- “开始命名”区域可直接选择离线翻译、NGR 云翻译、自有百度翻译、本地模型、本地知识库和 AI 命名。
- 命名页选择与“设置 → API”中的翻译服务双向同步，切换后按钮文字和实际调用服务保持一致。
- 保留回车翻译、服务可用性检查和失败原因提示。

## 全局快捷应用

- ArtHub 快捷入口从命名页移动到全局顶部栏，在首页、命名、检测和本地搜图页面都可使用。
- 默认增加 Figma 快捷入口，并自动检测当前电脑上的可执行文件。
- ArtHub、Figma 和其他应用均可自定义名称、路径、启用状态及显示顺序。
- 渲染页面只使用已登记的应用 ID，不能提交任意系统路径启动程序。

## 切图检测高级配置

- 按项目组新增最小尺寸、文件大小上限、普通切图单边上限、风险尺寸和错误/警告级别。
- 背景图、PC 效果图和移动端效果图尺寸均可独立配置。
- 策划模式可分别控制双数和 2 的幂次检查；Icon 模式可配置正方形要求与允许尺寸列表。
- 修复“图集倍数可以填写但检测逻辑仍固定为双数”的问题。
- 三种检测模式只显示对应规则，检测规范说明实时同步当前项目组配置。
- 格式安全规则保持不变：仅扩展名和文件内容均有效的 PNG 可以通过。

## 兼容与安全

- 旧检测项目组会自动补齐新字段，不清除已有配置或检测数据。
- 应用快捷方式仍由桌面主进程登记、校验和启动，不向渲染页面返回可执行文件路径。
- API 密钥仍由 Windows DPAPI 安全存储，不写入源码、安装包或日志。
- 本版本仍为未签名 Windows 安装包，系统可能显示“未知发布者”提示。

## 验证

- 完整自动化测试、Electron 开发版/测试版烟雾测试和版本一致性检查通过。
- GitHub Actions 使用干净环境生成正式安装版、自动更新元数据、SHA-256 校验和、SBOM 和构建清单。

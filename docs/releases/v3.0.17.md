# NGR AssetPilot v3.0.17

本版本整理“更多功能”入口，重做 Figma 图文教程，优化 TAPD 操作顺序，并接入快速找界面扩展工作台。

## 更多功能与 Figma 教程

- 首页辅助入口合并为“更多功能”：基地提单表、自动生成 TAPD 周报、Figma 一键变体和快速找界面。
- Figma 页面采用左侧章节导航、右侧图文阅读区，直接展示下载安装到一键变体的分步教程。
- 安装章节只显示第一集“下载安装”，变体章节只显示第二集“一键变体”；视频带哔哩哔哩标识、截图封面和播放键。
- 图文截图随软件保存，支持点击放大和离线阅读；下载及视频在系统浏览器打开。
- 移除首页左侧空白的“功能使用教程”浮动入口，保留顶部现有使用教程。

## TAPD 周报与图片

- 日期下方按操作顺序排列：1 登录 TAPD、2 抓取所选日期、3 提取 Bug 单图片。
- 更多采集收起为次要入口，导出功能单独成组。
- Bug 单图片支持提取、缩略图及放大查看，继续通过受限 IPC 读取本地已登记图片。
- 保留现有报表数据、登录状态和导出文件。

## 快速找界面扩展

- 接入 hostApi 1 扩展工作台，支持导入、管理和启动独立扩展 ZIP，并显示真实导入进度。
- 本版兼容并沿用快速找界面 0.7.0 扩展 ZIP；扩展、模型和资料独立存放，不附带进主安装包。
- 0.7.0 扩展当前单独交付，尚未提供公开下载；GitHub 已公开的旧独立版不能作为扩展导入。
- 宿主最低兼容版本为本次 3.0.17；旧 3.0.16 安装器不具备本次扩展接口。
- 每次本地构建和 CI 发布均显示扩展版本检查，离线时明确记录“未检查”，不阻断构建。

## 安装包与更新

- 仅保留简体中文、繁体中文和英文 Electron 资源，清理 sql.js 调试及重复发行文件。
- 保持原安装器与自动更新身份，附带 latest.yml、blockmap、SHA-256、SBOM 和构建清单。
- 沿用现有未签名发布方式；Windows 安装时可能显示“未知发布者”。

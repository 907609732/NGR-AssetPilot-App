# NGRAI辅助UI切图命名工具使用教程

适用版本：V2.26
教程用途：录屏讲解、团队培训、图文说明文档

## 一、视频讲解脚本

### 片头

画面：打开工具主界面，展示标题“NGR AssetPilot｜AI资源领航 V2.26”。

旁白：

大家好，这期视频给大家介绍 NGRAI 辅助 UI 切图命名工具。  
这个工具主要解决游戏 UI 切图在项目制作过程中“文件多、命名乱、手动改名慢、规范检查容易漏”的问题。

它有两个核心入口：

- 开始命名：上传 UI 切图，自动生成推荐命名，确认后批量导出。
- UI切图检测：上传资源文件夹，检查格式、分辨率、大图、图标尺寸和疑似重复资源。

### 第一部分：启动软件

画面：展示项目根目录，鼠标指向 `点击启动服务.html` 或打开 `app/index.html`。

旁白：

下载并解压工具后，进入文件夹。  
如果你看到“点击启动服务.html”，直接双击打开即可。  
打开后会进入工具主界面，顶部可以看到当前版本号，右上角有操作指引和命名规则设置。

画面操作：

1. 双击打开启动文件。
2. 进入主界面。
3. 点击右上角问号按钮，简单展示内置操作指引。

旁白：

如果是第一次使用，可以点击右上角问号，跟着软件内置的新手指引快速熟悉主要流程。

### 第二部分：配置项目命名规则

画面：点击右上角齿轮，进入“命名规则”页面。

旁白：

在正式命名前，建议先配置项目规则。  
这里可以设置项目、配置方案、固定前缀、工程名、分隔符和常用标签。

画面操作：

1. 点击右上角齿轮。
2. 在“选择你的项目”中选择项目。
3. 在“选择项目配置方案”中选择方案。
4. 设置固定前缀，例如 `T_UI`、`T_UI_Img` 或 `T_UI_Icon`。
5. 填写工程名。
6. 确认分隔符，一般使用下划线 `_`。

旁白：

命名最终会按类似这样的结构组合：  
`T_UI_工程名_界面名_自动生成名称.png`

如果项目组有自己的命名规范，可以在这里维护页面词库、组件词库、状态词库和文件名匹配规则。

### 第三部分：维护命名知识库

画面：滚动到“命名知识库”区域。

旁白：

命名知识库是这个工具比较重要的部分。  
页面词库可以填写常见页面，例如 Home、Shop、Login。  
组件词库可以填写 BG、Button、Icon、Banner、Item。  
状态词库可以填写 Normal、Hover、Active、Disabled。  
文件名匹配规则可以把中文关键词转换成英文命名，比如“登录=Login”“按钮=Button”。

画面操作：

1. 展示页面词库。
2. 展示组件词库。
3. 展示状态词库。
4. 展示文件名匹配规则。
5. 点击“保存规则”。

旁白：

保存后，这些规则会参与本地知识库命名、翻译 API 命名和 AI 视觉命名，让工具更贴合当前项目。

### 第四部分：配置 AI 和翻译 API

画面：展示“AI 接入”区域和右侧翻译面板设置。

旁白：

工具支持三种命名模式。  
第一种是百度翻译 API 命名，适合文件名本身包含中文语义的资源。  
第二种是本地知识库命名，不需要 API，速度最快，适合规则比较固定的批量资源。  
第三种是 AI 视觉命名，会读取图片内容，也可以结合参考效果图进行判断。

画面操作：

1. 在 AI 接入区域填写服务类型、接口格式、API 地址、API Key 和模型。
2. 点击“测试 API”。
3. 点击“保存 AI 配置”。
4. 打开右侧“翻译”面板。
5. 在翻译设置中选择本地词库、百度翻译 API 或 OpenAI 兼容文本模型。
6. 点击“测试 API”和“保存翻译设置”。

旁白：

如果没有 API，也可以直接使用本地知识库命名。  
如果配置了翻译 API，工具会只发送文本文件名，不会上传图片。  
如果使用 AI 视觉命名，工具会把切图图片发送给模型分析，所以建议根据项目保密要求选择模式。

### 第五部分：开始批量命名

画面：回到主界面，点击“开始命名”。

旁白：

配置完成后，回到主界面，点击“开始命名”。  
这里是日常使用最多的页面。

画面操作：

1. 点击“开始命名”。
2. 上传切图文件夹。
3. 如有需要，补充上传单张图片。
4. 如使用 AI 视觉命名，上传参考效果图。
5. 选择当前项目配置方案。

旁白：

上传文件夹后，切图会出现在待处理列表中。  
如果是整套界面，可以在上方填写当前界面工程名和当前界面命名。

### 第六部分：填写当前批次参数

画面：展示“前缀名、当前界面工程名、当前界面命名、批量添加后缀和序号、列表展示/排序”。

旁白：

这一排参数控制当前批次的命名结构。  
前缀名可以选择无、`T_UI`、`T_UI_Img`、`T_UI_Icon`。  
当前界面工程名一般填写项目或模块名称。  
当前界面命名可以填写页面名，例如 Home、Shop、Bag。

画面操作：

1. 设置前缀名。
2. 输入当前界面工程名。
3. 输入当前界面命名。
4. 切换完整列表、紧凑列表或画册模式。
5. 按原文件名 A-Z 排序。

旁白：

如果是一组按钮状态图，可以使用“批量添加后缀和序号”。  
比如批量追加 Hover、Normal，或者从 01 开始自动添加序号。

### 第七部分：选择命名模式并运行

画面：展示顶部“命名模式”和“运行”按钮。

旁白：

接下来选择命名模式。  
默认是百度翻译 API 命名，适合中文原始文件名。  
如果不想调用接口，可以选择本地知识库命名。  
如果希望模型根据图片内容识别，可以选择 AI 视觉命名。

画面操作：

1. 打开命名模式下拉框。
2. 依次展示三个模式。
3. 选择一种模式。
4. 点击运行按钮。
5. 展示命名进度。

旁白：

命名过程中可以点击“终止命名”。  
完成后，每张图片都会生成推荐名和最终名称。最终名称可以继续手动修改。

### 第八部分：逐张确认和手动微调

画面：展示待处理图片列表。

旁白：

命名完成后，不建议直接导出，最好先逐张确认。  
列表中可以看到原文件名、图片预览、尺寸信息、推荐名和最终名称。  
如果某张图命名不符合预期，可以直接修改最终名称。

画面操作：

1. 点击某张图片。
2. 修改最终名称输入框。
3. 展示词库辅助或推荐名选择。
4. 勾选多张图片。
5. 使用“只看问题图片”筛选异常资源。

旁白：

如果工具提示尺寸问题，可以点击“只看问题图片”集中处理。  
如果要批量删除某些资源，勾选后点击“删除选中图片”。

画册模式默认每页 `4 × 6` 张，横向 Gap 为 `112px`，纵向 Gap 为 `46px`。

可以在画册 Grid 工具栏调整列数、每页行数和两个 Gap。点击图片卡片后，宽屏会在右侧打开完整命名编辑栏，窄屏会改为底部抽屉。

### 第九部分：使用命名记录

画面：展示“命名记录”标签栏。

旁白：

如果一次要处理多套界面，可以使用命名记录。  
点击“新建”可以创建一套新的命名记录。不同记录之间会保留各自的图片列表、参考图、命名结果、选中状态、画册参数和当前命名参数。

页面会自动增量保存命名进度。需要立即保存时，点击“保存当前进度”，状态栏会显示“保存中”、“已保存时间”或失败原因。

刷新页面或完全关闭浏览器后，只要仍使用同一浏览器和同一工具地址，就会恢复上次的全部命名记录。

画面操作：

1. 点击“新建”。
2. 切换不同命名记录。
3. 双击记录名称进行重命名。
4. 点击小删除按钮删除记录。

旁白：

这样可以在同一个页面里处理多套系统界面，互不覆盖。

### 第十部分：导出命名完成图片

画面：选择“工程文件夹”或“ZIP 压缩包”，然后点击“导出全部命名图片”。

旁白：

确认所有图片都有最终名称后，先选择导出方式，再点击“导出全部命名图片”。
工具会保留原始图片内容，只改变文件名，不会重新压缩或重新编码图片。

画面操作：

1. 在“导出方式”选择“工程文件夹”或“ZIP 压缩包”。
2. 点击“导出全部命名图片”。
3. 选择“工程文件夹”时，选择保存位置；工具会在其中自动创建按工程名命名的子文件夹。
4. 选择“ZIP 压缩包”时，浏览器会下载按工程名命名的 ZIP，压缩包内仍按工程分文件夹。

旁白：

如果一次命名任务里有多个工程名，工具会自动分到多个工程文件夹。
如果浏览器不支持选择文件夹，工具不会再逐个散落下载，而会自动改为下载 ZIP 压缩包。

Windows 资源管理器若提示“你尝试预览的文件可能对你的计算机有害”，说明浏览器为图片添加了网络安全标记。确认图片来自本工具后，双击项目根目录的 `Windows一键解除图片预览限制.bat`，选择导出文件夹即可批量解除图片预览限制；也可以将导出文件夹直接拖到脚本上。脚本只处理常见图片格式，不会关闭 Windows 全局安全保护。

### 第十一部分：UI 切图检测

画面：回到主界面，点击“UI切图检测”。

旁白：

除了命名，这个工具还可以做切图规范检测。  
进入 UI 切图检测后，选择检测项目组、检测模式和重复检测灵敏度。

画面操作：

1. 点击“UI切图检测”。
2. 选择检测项目组。
3. 选择检测模式：NGR切图规范、策划配置切图规范、图标尺寸检测规范。
4. 根据需要开启重复检测。
5. 上传检测文件夹。

旁白：

NGR 切图规范会检查 PNG 格式、宽高双数、大图尺寸、2048 警告等。  
策划配置切图规范会检查是否符合 2 的幂次。  
图标尺寸检测规范会检查图标是否正方形，以及是否为 32、64、128、256、512、1024 这些规格。

### 第十二部分：查看检测结果和规则

画面：展示检测结果列表和“查看检测规范”。

旁白：

上传后，检测结果会显示在列表中。  
可以点击“查看检测规范”了解当前规则。  
也可以点击“只看问题图片”或“只看警告图片”集中处理异常资源。

画面操作：

1. 点击“查看检测规范”。
2. 点击“只看问题图片”。
3. 点击“只看警告图片”。
4. 展示异常提示。
5. 点击“清空检测列表”。

旁白：

重复资源检测默认关闭。开启后，工具会通过缩略像素指纹判断疑似重复资源。灵敏度越高，越容易发现相似资源，也越可能出现误报。

### 第十三部分：检测设置

画面：点击检测页齿轮，进入“检测设置”。

旁白：

如果项目组规范不同，可以进入检测设置单独维护项目组参数。  
这里可以设置单边上限、背景图尺寸、大图阈值、大图倍数和图集倍数。

画面操作：

1. 点击检测页齿轮。
2. 新增项目组。
3. 修改检测模式和参数。
4. 点击“保存检测参数”。

旁白：

保存后，回到检测页面就可以选择这套检测项目组。

### 片尾

画面：回到主界面，展示两个入口。

旁白：

总结一下，日常使用建议按这四步走：  
第一，先配置项目命名规则和知识库。  
第二，上传切图，选择合适的命名模式批量生成名称。  
第三，逐张确认最终名称，再导出命名完成图片。  
第四，在提交资源前，用 UI 切图检测检查格式、尺寸和重复资源。

这样可以减少手动命名时间，也能让项目组的资源命名更加统一、清楚、可追踪。

## 二、图文教程

### 1. 打开软件

操作：

1. 解压工具压缩包。
2. 双击 `点击启动服务.html`。
3. 进入 NGRAI 辅助 UI 切图命名工具主界面。

配图建议：

- 截图 1：工具文件夹根目录。
- 截图 2：软件主界面。
- 截图 3：右上角问号“操作指引”。

说明：

主界面有两个主要入口：

- 开始命名：用于批量生成和导出切图命名。
- UI切图检测：用于检查资源格式、尺寸和重复资源。

### 2. 配置命名规则

操作：

1. 点击右上角齿轮按钮。
2. 选择项目和项目配置方案。
3. 设置固定前缀、工程名、分隔符。
4. 填写页面词库、组件词库、状态词库和文件名匹配规则。
5. 点击“保存规则”。

配图建议：

- 截图 4：命名规则页面。
- 截图 5：命名知识库区域。
- 截图 6：保存规则按钮。

推荐填写示例：

```text
页面词库：
Home
Shop
Bag
Login

组件词库：
BG
Button
Icon
Banner
Item

状态词库：
Normal
Hover
Active
Disabled

文件名匹配规则：
首页=Home
商城=Shop
按钮=Button
背景=BG
图标=Icon
```

### 3. 配置 AI 或翻译 API

操作：

1. 在“AI 接入”区域填写 API 地址、API Key 和模型。
2. 点击“测试 API”。
3. 测试成功后点击“保存 AI 配置”。
4. 需要翻译文件名时，展开右侧“翻译”面板。
5. 选择翻译方式并保存。

配图建议：

- 截图 7：AI 接入区域。
- 截图 8：测试 API 成功提示。
- 截图 9：右侧翻译面板设置。

注意：

- 本地知识库命名不需要 API。
- 翻译 API 命名只处理文本文件名。
- AI 视觉命名会读取图片内容，适合需要识别切图语义的场景。

### 4. 上传切图并填写当前批次参数

操作：

1. 回到主界面，点击“开始命名”。
2. 上传切图文件夹。
3. 需要时补充上传单张图片。
4. 使用 AI 视觉命名时，可上传参考效果图。
5. 选择当前项目配置方案。
6. 填写当前界面工程名和当前界面命名。

配图建议：

- 截图 10：开始命名页面。
- 截图 11：上传切图文件夹区域。
- 截图 12：当前批次参数区域。

命名结构示例：

```text
T_UI_NGR_Home_Button_Normal.png
T_UI_Img_NGR_Shop_BG.png
T_UI_Icon_NGR_Bag_Item_01.png
```

### 5. 选择命名模式

操作：

1. 打开“命名模式”下拉框。
2. 根据素材情况选择模式。
3. 点击运行按钮。
4. 等待命名完成。

配图建议：

- 截图 13：命名模式下拉框。
- 截图 14：命名进度。
- 截图 15：命名完成后的待处理列表。

模式选择建议：

| 模式 | 适合场景 | 是否需要 API |
| --- | --- | --- |
| 百度翻译API命名 | 原文件名包含中文语义 | 需要百度翻译配置 |
| 本地知识库命名 | 规则固定、追求速度、离线使用 | 不需要 |
| AI视觉命名 | 需要根据图片内容判断按钮、图标、背景等语义 | 需要 AI 配置 |

### 6. 确认和修改最终名称

操作：

1. 查看每张图片的推荐名和最终名称。
2. 对不合适的最终名称直接手动修改。
3. 使用“全选当前列表”批量选择图片。
4. 使用“批量添加后缀和序号”快速处理状态图或序列图。
5. 使用“只看问题图片”筛选异常资源。

配图建议：

- 截图 16：待处理图片列表。
- 截图 17：最终名称输入框。
- 截图 18：批量添加后缀和序号。
- 截图 19：只看问题图片。

常用批量操作：

- 追加后缀：给选中图片统一追加 `Hover`、`Normal`、`Selected` 等状态词。
- 添加序号：给选中图片从 `01` 开始连续编号。
- 删除选中图片：移除不需要处理的资源。

### 7. 使用命名记录

操作：

1. 点击“命名记录”旁边的“新建”。
2. 为不同界面创建独立记录。
3. 双击记录标题修改名称。
4. 点击记录右侧删除按钮删除记录。

配图建议：

- 截图 20：命名记录栏。
- 截图 21：新建命名记录。
- 截图 22：双击重命名。

说明：

命名记录会保存当前图片、最终名称、推荐名、勾选状态、词库展开状态和命名参数。适合一次处理多套界面。

### 8. 导出命名完成图片

操作：

1. 确认所有图片都有最终名称。
2. 点击“下载全部命名完成图片”。
3. 选择导出文件夹。
4. 在文件夹中检查导出的命名结果。

配图建议：

- 截图 23：下载全部命名完成图片按钮。
- 截图 24：选择导出文件夹。
- 截图 25：导出后的文件列表。

注意：

工具只改变文件名，不会重新压缩图片，不会改变像素，也不会修改图片内容。

### 9. 使用 UI 切图检测

## 四、对外介绍短文案

NGRAI 辅助 UI 切图命名工具是一款面向游戏 UI 资源整理流程的本地 Web 工具。它支持批量上传切图、按项目规则自动生成英文命名、AI 视觉识别、百度翻译 API 命名、本地知识库离线命名、批量添加后缀和序号、命名记录管理，以及切图格式、尺寸、图标规格和疑似重复资源检测。工具导出时只修改文件名，不重新编码图片，适合项目组统一资源命名规范、降低手动改名成本，并在提交前提前发现切图规范问题。

## 五、常见问题

### 没有 API 能不能用？

可以。选择“本地知识库命名”即可离线生成推荐名称。

### 百度翻译 API 命名会上传图片吗？

不会。百度翻译 API 命名只处理文本文件名。

### AI 视觉命名适合什么时候用？

适合原文件名没有语义，或者需要根据图片内容判断是按钮、背景、图标、状态图的情况。

### 导出会不会改变图片内容？

不会。工具导出时保留原始文件内容，只改变文件名。

### 为什么要先配置词库？

词库越符合项目习惯，自动命名结果越稳定。项目组可以把常用页面、组件、状态和中文关键词提前沉淀到配置方案中。

### 检测里的黄色警告是不是必须修改？

黄色警告表示允许但不推荐，需要根据项目要求判断。红色或问题项一般建议优先处理。

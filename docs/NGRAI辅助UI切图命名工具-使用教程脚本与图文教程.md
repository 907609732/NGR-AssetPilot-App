# NGR AssetPilot 桌面版使用教程

适用版本：**Windows 桌面正式版 v3.0.24**（2026-11-04 发布）。

核对日期：2026-11-06。

用途：日常使用、团队培训、录屏讲解。

本教程按 [v3.0.24 发布页](https://github.com/907609732/NGR-AssetPilot-App/releases/tag/v3.0.24)和对应源码编写，保留原文件名以兼容已有链接。普通用户安装 Release 中的 Windows 安装包；截至核对日期，`main` 的程序源码仍为 v3.0.11，需要开发或修改软件时请看[桌面开发与构建说明](../README-DESKTOP.md)，选择对应版本源码。

## 一、下载和安装

### 安装前准备

- 使用 Windows 10/11 x64 电脑。
- 批量命名、切图检测和本地知识库可以直接使用；自有在线 AI 服务需要自行配置接口。
- 本地 AI 搜图需要先下载或导入模型；模型和图库分析完成后可离线搜索。
- 使用 TAPD 报表时，电脑需要安装 **Google Chrome**，并能登录自己的 TAPD 账号。

### 安装步骤

1. 打开[最新正式版下载页](https://github.com/907609732/NGR-AssetPilot-App/releases/latest)，展开 **Assets**。
2. 下载 Windows x64 Setup 安装器。本教程对应的文件为 [NGR-AssetPilot-3.0.24-Setup-x64.exe](https://github.com/907609732/NGR-AssetPilot-App/releases/download/v3.0.24/NGR-AssetPilot-3.0.24-Setup-x64.exe)。
3. 双击安装器，按向导选择安装目录并完成安装。
4. 从桌面或开始菜单打开 **NGR AssetPilot**，在顶部或“设置 → 数据与关于”确认版本。

Release 中的文件用途如下：

| 文件 | 用途 |
| --- | --- |
| `NGR-AssetPilot-版本号-Setup-x64.exe` | 普通用户安装的软件 |
| `NGR-AssetPilot-版本号-SHA256SUMS.txt` | 核对下载文件的 SHA-256 |
| `latest.yml`、`.exe.blockmap` | 应用内自动更新使用的元数据 |
| SBOM、构建清单、扩展检查报告 | 构建与组件核查资料 |
| `Source code (zip / tar.gz)` | 开发用源码，不是安装包 |

v3.0.24 沿用未签名构建，Windows 可能显示“未知发布者”；安装前核对官方发布页与校验值。安装完成后直接启动桌面软件，仓库中的 `点击启动服务.html` 只属于旧浏览器兼容入口。

## 二、第一次使用：先跑通一小批图片

1. 打开右上角“设置”，进入“命名规则”。选择项目和配置方案，确认前缀、工程名、分隔符和常用词库。
2. 返回首页，点击“开始命名”。在“上传切图”中选择文件夹或图片，也可以拖入文件夹。
3. 在运行按钮右侧打开“选择命名服务”，先选“内置离线 AI 翻译”或“本地知识库命名”。
4. 检查“当前界面工程名”和“当前界面命名”，点击运行按钮。
5. 逐张检查最终名称，处理重复命名，再选择工程文件夹或 ZIP 导出。
6. 点击“保存当前进度”，看到保存成功后再退出。

“上传切图”是把文件导入当前工作区。是否发送到外部服务，取决于随后选择的命名服务；本地知识库和离线翻译不上传文字或图片。

设置分为以下几个页签：

| 页签 | 主要内容 |
| --- | --- |
| 数据与关于 | 软件版本、检查更新、工作区备份、开机自启动、防止息屏 |
| 命名规则 | 项目、配置方案、前缀、词库、匹配规则、上下文和提示词 |
| 切图检测 | 检测项目组、尺寸阈值、重复检测和各类检测规则 |
| 本地搜图 | 模型管理、创建图库和本机推理设备状态 |
| API | 视觉命名和文本翻译服务配置 |
| 功能测试 | 本地核心自检、当前命名服务测试和运行状态 |

## 三、选择命名服务和配置 API

当前版本提供六种命名服务，不要求所有用户都填写 API Key：

| 服务 | 适用场景 | 准备工作 |
| --- | --- | --- |
| 内置离线 AI 翻译 | 原文件名有中文含义，需要转为英文命名词 | 使用内置中译英模型，无需 API Key |
| NGR 云翻译 | 希望通过托管翻译服务处理中文名称 | 需要联网；是否可用以客户端服务状态为准 |
| 自有百度翻译 API | 使用自己的百度翻译服务 | 在“设置 → API”填写对应配置并测试 |
| OpenAI 兼容文本模型 | 使用自己的文本模型进行翻译和命名 | 填写接口地址、API Key 和模型名称并测试 |
| 本地知识库命名 | 命名规则固定，词库中已有所需关键词 | 先维护项目词库和文件名匹配规则 |
| AI 视觉命名 | 原名信息不足，需要结合图片内容判断 | 配置支持视觉的模型，可补充参考效果图 |

使用自有服务时，在“设置 → API”填写并保存配置，点击“测试 API”。视觉配置和翻译配置各有保存按钮。切回命名页后，确认运行按钮显示的是准备使用的服务。

文本翻译会向所选服务发送待译文字；AI 视觉命名会发送选用的切图、参考图和相关命名上下文。桌面版密钥通过 Windows 安全存储保存，换电脑后需要重新填写。不要修改 `local-config.js`，它已经不作为运行时配置来源。

## 四、批量命名、检查和导出

### 1. 配置项目规则

进入“设置 → 命名规则”，选择项目和配置方案，维护：

- 基础结构：固定前缀、工程名、分隔符。
- 页面词库：例如 `Home`、`Shop`、`Login`。
- 组件词库：例如 `BG`、`Button`、`Icon`。
- 状态词库：例如 `Normal`、`Hover`、`Disabled`。
- 文件名匹配规则：例如把项目常用中文词映射为约定英文或拼音。
- 项目上下文和 AI 提示文本：用于说明团队的命名偏好。

保存规则后，可导出当前方案模板供团队维护；模板用于命名方案，不等于完整工作区备份。

### 2. 导入并填写本批次参数

在“开始命名”中上传切图，选择“当前项目配置方案”，填写“前缀名”“当前界面工程名”和“当前界面命名”。使用 AI 视觉命名时，可在“上传参考效果图”中补充整体界面。

例如，前缀为 `T_UI`、工程名为 `Demo`、界面名为 `Home`，最终组合形式可类似 `T_UI_Demo_Home_Button.png`；实际大小写、分隔符和名称组成以所选方案为准。

### 3. 运行并人工确认

选择服务后点击运行按钮。任务进行中可点击“终止命名”。完成后检查原文件名、图片预览、推荐名和最终名称，需要时直接编辑最终名称。

大量图片可切换完整列表、紧凑列表或画册模式。画册列数、每页行数及间距可调整，点击卡片可打开对应的命名编辑区域。对按钮状态等成组资源，可使用“批量添加后缀和序号”。

同一工程目录内的重复导出名会标红并阻止导出。可用“只看问题图片”集中处理，再继续导出。“删除选中图片”只移出当前工作区，不会删除磁盘源图片。

### 4. 导出文件

打开“下载设置”，选择导出方式，再点击“下载命名完成的图片”：

- **工程文件夹**：选择目标位置，按每张图片的工程名分目录导出。
- **ZIP 压缩包**：本地打包下载，压缩包内同样按工程分目录。

命名导出只改变文件名，不重新编码图片内容。导出前确认名称与目标目录，导出后抽查文件名和文件内容。

### 5. 保存多批次进度

“命名记录 → 新建”可创建另一批任务。不同记录保留各自的图片、参考图、命名结果和编辑参数；软件会自动保存，也可点击“保存当前进度”立即保存并查看状态。

桌面版再次启动会读取本机保存的主工作区。备份或换电脑使用第十节的 `.ngrap` 流程。

## 五、UI 切图检测

1. 从首页进入“UI切图检测”。
2. 选择检测项目组和模式：NGR 切图规范、策划配置切图规范或图标尺寸检测规范。
3. 点击“查看检测规范”，先核对当前方案的要求。
4. 上传检测文件夹或图片，查看通过、警告和问题结果。
5. 用“只看问题图片”“只看警告图片”筛选，修改源文件后重新检测。

格式检测固定要求 PNG，并核对扩展名与文件内容。其余尺寸规则由检测项目组控制，包括普通切图单边上限、特殊风险尺寸、大图或图集的宽高倍数、背景图及效果图尺寸、Icon 尺寸等。**教程中的示例尺寸不能代替当前项目的检测配置。**

重复检测默认关闭。开启后会标记像素相近的疑似重复资源；灵敏度越高越可能出现误报，需要人工判断。切图检测提供检查结果，不会自动修复图片，也不会自动删除源文件。

## 六、本地 AI 搜图

本地 AI 搜图和“AI 视觉命名”是两套独立功能。本地搜图使用本机模型和图库索引，不需要填写在线视觉 API Key。

### 1. 准备模型

进入“设置 → 本地搜图”：

- 联网电脑点击“下载内置模型”。
- 离线电脑点击“导入 .ngrmodel”，选择已准备好的模型包。
- 已有符合要求的 ONNX 特征模型时，可在“模型管理”中导入并通过隔离校验。

图文双塔模型可支持图片和文字搜索；图像单塔模型只提供图片搜索。切换模型使用各自独立的索引，首次切换到新模型后需要分析图库。

### 2. 创建和分析图库

1. 点击“新建图库”，选择存放图片的本地文件夹。
2. 返回“本地 AI 搜图”，选择当前图库，点击“开始分析”。
3. 等待递归扫描、特征分析与索引写入完成，查看跳过和错误数量。
4. 后续新增或修改图片时，再次分析以增量更新索引。

Windows 会尝试使用 DirectML 加速；设备不兼容时可回退 CPU。无需为内置流程单独安装 CUDA 或 Python。速度受电脑配置、图片数量和模型影响，以软件显示为准。

### 3. 查找资源

- **截图 / 图片搜索**：粘贴截图、拖入图片或选择查询图。
- **文字搜索**：使用支持文字搜索的模型，输入中文或英文描述。
- **素材库浏览**：没有提交搜索时，可按文件夹及名称等条件浏览已建库资源。

源图库保持只读，“删除索引”删除的是应用维护的索引和缩略图，不会删除原图。索引、模型和缩略图保存在本机；模型就绪后的图库分析及搜索可离线运行。

## 七、基地提单表：粘贴日报生成表格

“基地提单表”使用手动粘贴的日报原文，在本机解析；它与下面需要登录、采集的 TAPD 报表是两个入口。

1. 打开“更多功能 → 基地提单表”。
2. 在“日报原文”中粘贴需要处理的内容，检查提单默认值，如工作量单位、制作人员和尺寸。
3. 点击“解析日报”，查看按日期、分类、S 等级和工时整理的结果。
4. 人工核对任务行及工时合计，需要时编辑表格，或使用“重新平均分配工时”。
5. 点击“复制表格”粘贴到已有表格，或点击“导出 Excel”保存文件。

此流程不需要登录 TAPD 或配置 AI API。原始日报不会因解析而修改；解析结果和默认值仍需按实际业务核对。

## 八、TAPD 周报、月报和 Bug 媒体

### 1. 登录并采集

1. 从首页“更多功能 → 自动生成TAPD周报”打开报表窗口。
2. 选择周报或月报和日期；周报可使用“本周”“上周”“今天”等快捷日期。
3. 点击“登录 TAPD”，在软件打开的专用 **Google Chrome** 窗口中完成登录。
4. 返回报表窗口，点击“抓取所选日期”，等待采集完成。
5. 检查“上次抓取”时间及覆盖范围。显示时间为北京时间；日期超出已采集范围时重新抓取。

这里读取的是登录账号可见的 TAPD 已办内容。普通 Chrome 窗口中的登录状态不能代替专用窗口登录；登录过期时按提示重新登录即可。

### 2. 确认等级、分类并导出报告

核对预览中的事项、S 等级和分类。存在待确认项时，先补充或修改；需要保留未完成结果时，可以明确勾选“导出草稿”。

S 等级优先采用人工调整，其次采用标题中的等级；标题没有等级时，在采集过程中读取详情页“修复分支”，例如 `Trunk_S2` 对应 S2。v3.0.24 会等待该字段异步加载。旧快照不会自动补齐新字段，需要重新点击“抓取所选日期”。

- 点击“复制周报”取得周报正文；正文可独立选择附加日期和人天，每条内容显示 S 等级。
- 点击“下载月报 Excel”导出报表。
- “更多导出”提供周报单列表格、TXT、Markdown 和原始清单 CSV 等选项。

当前报表带有既定的人员、供应商和分类等模板默认值。用于不同团队时应复核导出表中的这些字段。

### 3. 提取 Bug 图片和视频

1. 完成所选范围的采集后，点击“提取 Bug 图片和视频”。
2. 选择保存位置，等待提取结束，查看成功和失败数量。
3. 打开“Bug 媒体”页，按单号或标题查找，查看图片、复制完整图片、播放视频或定位文件。

当前版本从 Bug 描述、评论和附件中提取可下载媒体，并过滤 TAPD 全局 AI 助手的推广图。列表缩略图用于浏览，放大和复制使用保存的完整图片。旧导出目录中的推广图不会自动清理，需要重新提取到新目录。

媒体下载支持可直接取得的图片及 MP4、WebM、MOV/M4V 视频；单图片上限 50 MB，单视频上限 250 MB。无法直接下载的 `blob:`、HLS/DASH 播放列表会记入失败清单；本机播放器不支持视频编码时，可用“定位文件”交给其他播放器打开。

### 4. 在月报中附上 Bug 图片

先完成媒体提取，再勾选 **“月报附带 Bug 图片”**，点击“下载月报 Excel”。软件把当前报告范围内已提取的图片放入独立的 **`Bug图片附件`** 工作表；视频继续在“Bug 媒体”页查看。

若保存媒体的目录被移动或删除，需要重新提取后再导出附图月报。仅勾选该选项不会自动补抓图片。

## 九、快速找界面扩展

快速找界面是独立扩展，需要另外取得兼容的官方扩展 ZIP 和对应模型。**主安装包不附带该扩展及其模型。**

截至 v3.0.24 发布时，宿主记录的已验证扩展版本为 **0.7.0**，该扩展包仍为单独交付；[扩展项目发布页](https://github.com/907609732/lingtu-interface-finder-releases/releases/latest)上的公开 0.5.7 属于旧独立版，不能拿来导入宿主。

收到兼容扩展包后：

1. 如果扩展工作台正在运行，先关闭工作台；打开“更多功能”，点击“快速找界面”旁的齿轮管理按钮。
2. 点击“导入扩展 ZIP”，选择收到的原始 ZIP 包。
3. 等待解包、检查和完整校验，确认版本及扩展状态。
4. 点击“打开工作台”，按扩展自身界面准备模型和项目。

v3.0.24 的首次导入和“重新检查”会完整校验文件；日常打开复用持久校验记录，发现文件变化或记录异常时再完整检查。旧安装升级后的第一次打开也需要建立校验记录，因此这一次可能比之后的打开慢。

## 十、保存、备份与从旧 Web 版迁移

### 主工作区备份

打开“设置 → 数据与关于 → 工作区迁移与备份”，点击“导出 .ngrap”。该迁移包保存设置、命名记录、切图和参考图。导入时点击“导入 .ngrap”，软件校验包内容，并在替换当前工作区前自动生成一份备份。

桌面版不会把 Windows 安全存储中的 API Key 导出到迁移包。新电脑导入后重新填写密钥；旧版带加密凭据的迁移包仍可导入，需要输入原迁移密码。

`.ngrap` 不是整机备份：本地搜图模型与索引、TAPD 报表和专用 Chrome 资料、扩展文件和项目资料不属于这份主工作区迁移包的完整覆盖范围。搬家或重装时要分别处理这些资料，详见[数据与安全性说明](安全性说明.md)。

### 从原浏览器版本搬到桌面版

1. 使用原来的浏览器和原工具地址打开仍保有记录的旧版工具。
2. 在支持数据迁移的旧版工具中导出 `.ngrap`。
3. 打开桌面正式版，在“数据与关于”导入该迁移包。
4. 核对项目、命名记录、图片与参考图；根据需要重新填写 API 配置。

原浏览器的记录不会因为安装桌面软件而自动搬入。若使用的更早版本没有 `.ngrap` 导出入口，请先保留原站点数据，并导出已有图片和方案；本教程不承诺自动读取任意旧浏览器记录。确认迁移完成前保留原站点数据和导出的备份。正式版、开发版和测试版的主工作区分开保存；TAPD 等独立工具的数据范围见安全性说明。

## 十一、更新与常见问题

### 更新正式版

进入 **“设置 → 数据与关于 → 检查更新”**。发现新版本后阅读更新说明，确认当前任务已完成，再点击“下载更新”。下载完成后，软件会自动保存工作区、退出、安装并重新打开，无需再点一次安装。

如果无法在线更新，可从[官方 Releases](https://github.com/907609732/NGR-AssetPilot-App/releases)下载相应 Setup 安装器手动更新。开发版和测试版的更新方式见[开发说明](../README-DESKTOP.md)。

| 遇到的问题 | 处理方法 |
| --- | --- |
| 解压源码后找不到可以直接运行的程序 | 去 Release 下载 `Setup-x64.exe`；源码 ZIP 用于开发 |
| 打开的是浏览器页面，本地搜图或扩展不可用 | 从桌面或开始菜单启动 NGR AssetPilot 桌面软件 |
| 没有 API Key | 先选内置离线 AI 翻译或本地知识库命名；本地搜图独立准备模型 |
| 在线命名失败 | 检查当前服务、接口地址、模型和密钥，并在 API 设置中测试；需要继续整理时可切换离线服务 |
| 无法导出，图片提示重复命名 | 修改同一工程目录中的冲突名称后重试 |
| 本地搜图没有结果或文字搜索不可用 | 确认图库分析完成、当前模型对应索引已建立，文字搜索需要支持图文的模型 |
| TAPD 无法打开登录窗口 | 确认已安装 Google Chrome，并关闭上一次未正常结束的专用采集窗口后重试 |
| TAPD 仍显示旧数据或 S 等级未补齐 | 查看“上次抓取”时间，重新抓取所选日期后再确认等级 |
| 月报没有 Bug 图片 | 先提取媒体，再勾选“月报附带 Bug 图片”；确认原保存目录仍可访问 |
| 快速找界面不能导入下载的 EXE | 需要单独交付的兼容扩展 ZIP，旧独立版安装包不能导入 |
| 换电脑后 API 不可用 | `.ngrap` 不导出桌面版密钥，在新电脑重新填写并测试 |

以下脚本适合录制一段桌面版上手视频。画面使用实际 v3.0.24 安装版；旧 Web 版截图可作为历史资料，不作为当前操作画面。

| 镜头 | 画面与操作 | 讲解要点 |
| --- | --- | --- |
| 1. 下载与启动 | 展示 Release 的 Setup 安装器，安装后从快捷方式打开软件，显示版本 | “这是 Windows 桌面版 NGR AssetPilot。普通用户下载 Setup 安装器，安装后直接打开。” |
| 2. 项目配置 | 打开设置中的命名规则，选择项目与方案，展示前缀和词库 | “先把团队规则保存为方案，后续处理不同界面时复用。” |
| 3. 一次命名 | 导入一小批图片，选择离线翻译或本地知识库，填写工程名和界面名并运行 | “不填 API 也能先跑通流程，需要视觉识别时再配置相应模型。” |
| 4. 确认与导出 | 修改最终名称、演示重名提示，导出工程文件夹或 ZIP | “先确认名称和冲突，再导出；图片内容不会因命名重新编码。” |
| 5. 切图检测 | 展示当前检测规范、导入样本、筛选问题和警告 | “尺寸阈值取决于项目方案；疑似重复需要人工判断。” |
| 6. 本地搜图 | 展示模型就绪、创建图库、分析完成、粘贴截图搜索 | “模型和索引准备好后，可以在本机离线查找相似资源。” |
| 7. 基地提单表 | 粘贴日报、解析、核对工时、导出表格 | “已有日报可以直接在本机整理成表格，无需登录 TAPD。” |
| 8. TAPD 报表 | 在专用 Chrome 登录，抓取所选日期，确认等级并预览周报 | “先看采集时间，再确认 S 等级和分类，最后复制或导出。” |

| 10. 扩展与备份 | 展示快速找界面扩展管理，再到数据与关于导出 `.ngrap` | “扩展和模型单独准备；主工作区可以备份，换电脑后密钥需要重新配置。” |

# 快速找界面扩展工作台

宿主 3.0.17 支持 `hostApi: 1` 的快速找界面 0.7.0 扩展 ZIP。它复用 AI资源领航的 Electron 和主进程，业务界面在宿主管理的独立工作台窗口显示，不启动快速找界面 EXE、Node 服务或 HTTP 端口。Python RTX 推理仍是本地子进程；模型保持独立下载/导入。

## 安装与打开

1. 使用包含本次适配改动的 AI资源领航，打开“更多功能 → 快速找界面”旁的管理入口。
2. 点击“导入扩展 ZIP”，通过原生选择器选择 `quick-interface-finder-0.7.0-extension.zip`。无需先解压。
3. 安装完成后点击“打开工作台”。重复打开复用同一窗口；关闭工作台不会退出 AI资源领航。
4. 升级前关闭工作台，再导入新版扩展 ZIP。旧安装目录、项目资料和模型保留；校验失败时继续使用原版本。

扩展目前为本地单独交付，管理界面的下载按钮暂时隐藏。旧独立 EXE 发行 ZIP 不是此扩展格式，不能导入。最低宿主版本为 3.0.17，生产包已完成下方实际扩展验收；旧 3.0.16 安装器不含本次 hostApi 1 接口，需升级宿主后再导入。

## 目录与数据

- 扩展：`%APPDATA%/NGR/extensions/quick-interface-finder/v<版本>-<清单摘要>/`。
- 当前版本指针：上述目录的 `current.json`，完整写入并校验后原子切换。
- 配置：`<宿主 userData>/extensions-data/quick-interface-finder/`。
- 本机缓存：`<宿主 userData>/extensions-cache/quick-interface-finder/`。
- 首次继承：只读取 `%APPDATA%/QuickInterfaceFinder/settings.json` 中原来的项目路径和模型路径，不移动原项目，不复制账号，不共用运行中的 SQLite/LanceDB。

测试通过 `NGR_E2E_USER_DATA` 隔离宿主资料、扩展安装目录和初次继承来源，不读写真实用户库。实际项目文件格式、原文件名、GM/Figma 和 Git 特征同步方式由快速找界面业务运行时继续维护。

## 加载与权限边界

ZIP 必须只有一个 `quick-interface-finder-<版本>` 根目录，包含 `extension.json` 以及 `resources/app.asar`、`resources/worker` 和 `resources/media-tools`；另允许经过清单哈希校验的 `resources/使用说明.md`、`resources/第三方组件说明.md`。清单必须指定固定 ID、Windows x64、hostApi 1 和固定入口 `resources/app.asar/desktop/main.cjs`；不会执行清单中的任意入口。安装拒绝路径越界、符号链接、加密 ZIP、重复名称、未登记文件、异常大小和 SHA-256 不一致。每次首次打开工作台会重新校验所有文件的哈希。

这些检查用于身份格式和完整性检查，**不是代码签名或发布者认证**。扩展包含可执行的第一方本地代码，只应导入可信来源提供的官方扩展包。主界面 renderer 只能唤起原生 ZIP 选择器，不能传入任意安装路径；打开扩展必须由用户明确操作触发。

宿主在 ready 前用同一次调用固定注册原 `ngr-assetpilot` 和 `library` scheme，不提前载入未安装包。原宿主 scheme 权限、CSP 和主窗 IPC 来源限制不变。工作台使用独立 session、专用 preload 与 quick IPC；宿主主界面的 sender/main-frame 校验保持原样，不把扩展加入主界面权限白名单。退出宿主时统一释放扩展 watcher、模型下载和推理进程。

## 导入进度与响应性修复（2026-10-24）

扩展管理现在显示读取、检查清单、解压校验、完成安装等步骤，以及当前阶段进度、实际文件数、处理字节、当前文件和用时。不知道总进度的阶段显示动态等待条，不生成虚构百分比；减少动态效果时显示静态等待提示。关闭面板不取消后台导入，再次点击扩展入口可恢复查看；失败后可重新选择 ZIP。

复用原有 adm-zip，把读取大包、解压和完整校验放到 Node worker_threads。状态通过现有 status IPC 获取，没有新增 renderer 文件权限。忙碌状态只读内存快照；空闲状态只检查安装元信息，避免每次轮询遍历全部载荷。真正加载代码前仍由 worker 完整检查目录、链接、大小及 SHA；不因显示进度而省略安全校验。宿主 ASAR 内的 worker、共享模块及依赖已经用真实 Electron 43 探针验证，无需新增 asarUnpack。

相关后台与 UI 测试合计 **22／22 通过**。使用原 301,560,575 字节 ZIP 的真实宿主导入，采集 54 次进度变化，验证文件／MB、关闭重开、安装成功、坏包报错与旧 current.json 保留、正常退出，未加载 GPU。最后对同一个已安装的 1,736 载荷目录补测，5 次空闲状态 IPC 查询约 20–80 ms，先前一次完整遍历查询约 4,914 ms。另验证等待动画、确定值、取消态和减少动态效果。

50 ms 定时心跳仅用于观察响应性，不是 FPS：第二轮真实导入 renderer 最大间隔约 61 ms，主进程仍有一次约 1,147 ms 间隔。首轮约 1,534 ms 峰值及触发自定阈值的记录保留，未宣称主进程完全无停顿。相关记录、阶段采样和截图在 `E:/快速找界面/artifacts/extension-import-progress`。

这项修复位于宿主源码，原 0.7.0 扩展 ZIP 无需更换；当前源码开发版需正常退出并重新启动后生效。此轮修复未写真实用户资料；现已纳入 3.0.17 生产包验收。

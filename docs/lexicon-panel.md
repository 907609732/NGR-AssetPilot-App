# 左侧分类词库

词库和翻译入口固定在窗口左侧。词库使用约 560 像素宽的非模态面板，靠窗口上方显示并在底部预留图片区，词条列表在面板内独立滚动；翻译面板约 340 像素宽，取消固定最小高度并根据实际内容自然收紧，展开服务设置时再增长。两个面板均从左侧展开，并可继续操作页面。两种面板互斥展开。关闭按钮和 Esc 可收起词库，同一次运行内保留搜索、分类、已加载数量和滚动位置。

两个入口使用品牌青绿色渐变、常驻高亮外圈和错开的 5 秒低频呼吸提示；悬停时轻微浮起，打开时播放一次星点闪烁和高光扫过。词库与翻译面板采用约 82% 半透明渐变、20px 背景模糊、内高光和多层阴影，内部输入框与列表使用分层半透明底色。系统开启“减少动态效果”时保留静态高亮和玻璃底板，停用呼吸、闪烁、扫光与滑入动画。

完整列表、紧凑列表和画册编辑区不再显示展开式词库，名称输入框及原有推荐词保留。面板顶部显示当前编辑图片的缩略图、原文件名和当前名称。词条点击只修改当前图片，不作用于勾选图片；再次点击移除该词，其他名称片段保留，并沿用原有命名格式、重名检查及保存流程。

词库复用内置词、当前方案及工程历史数据。英文、中文释义及中文别名均可搜索，英文不区分大小写；默认搜索全部，选中分类后限定范围。索引覆盖完整数据，每批显示 80 条，可继续加载。释义来自本地映射，未知词显示“暂无中文释义”，构建和搜索词库不调用云翻译。工程或方案变化时刷新相关分类。

没有当前图片或离开命名页面时仍可浏览搜索，应用按钮禁用。历史记录中的旧词库展开字段被忽略，不迁移或删除历史名称。没有新增 IPC 或云端接口。

# 快速找界面校验优化

目标：导入和手动“重新检查”完整校验，日常打开比对文件元信息，变化时回退完整校验。项目、模型和扩展接口不变，不打包。

设计：沿用现有 worker 和清单校验。成功完整校验后，在扩展安装目录之外（安装根目录内）原子保存按安装路径、清单哈希和文件元信息绑定的记录。日常打开仍遍历文件、拦截额外文件及符号链接，比较 size/mtime/ctime/ino/dev；全部一致时跳过内容读取。记录缺失、损坏或任一文件变化时完整计算哈希。旧安装第一次打开建立记录，跨管理器重启复用；导入完成即建立记录。手动重新检查强制完整校验，与打开/导入互斥，并支持退出取消。

限制：元信息缓存用于避免重复磁盘读取，不承诺防御能同时伪造缓存和文件的同用户恶意程序。完整哈希校验始终保留为显式检查入口。

验证：finder-extension、progress-ui、desktop-core 共 55 项，54 通过，1 项打包产物检查因未打包跳过。Electron 43.4.1 的 ASAR worker 验证缓存打开不产生全量哈希进度，强制检查产生真实全量进度。隔离资料目录的源码版启动与真实“重新检查”按钮 IPC 通过。

# 源码开发入口

用户已确认：以 v3.0.23 工作树为准，日常修改后直接打开源码开发版；已有开发版先保存并重启；正式发布时才打包验收。功能和正式版资料保持不变。

方案：复用 Electron 官方源码运行方式和已有 `npm run dev`（仅预编译 TAPD 小型 bundle），新增 `npm start`、中文双击入口及桌面快捷方式。不引入 Tauri、Vite 或自动监视器；不自动下载依赖或模型，不生成安装包。相比自动热重载，显式重启不会在保存代码时打断正在进行的业务操作。

重启只允许未打包 Dev 身份、同一规范化源码目录，通过 `app.relaunch()` 和已有 `QuitCoordinator` 的保存/服务清理流程执行；重复请求只安排一次重启。其他工作树的 Dev 正在运行时，显示实际目录并提示退出后再开，不能静默展示旧代码。启动期间的请求延迟到初始化完成处理。源码准备失败时不请求重启。

验收：重启边界单元测试、真实 Electron 保存后重启与进程交接、已有源码启动/托盘/打包配置测试。不构建或发布安装器。源码验证不替代发布时的安装、更新、签名和打包资源验收。

## V2.26 - 重复命名实时检测

更新日期：2026-08-13

更新类型：命名安全 / 交互提示 / 导出保护

### 更新内容

- 同一条命名记录中若多张待处理图片生成相同的工程目录与导出文件名，所有冲突图片都会实时标红并显示“重复命名”。
- 重名提示会指出另一张冲突图片的原文件名和同名数量，修改前缀、工程名、界面名或最终名称后自动重新检测。
- 完整列表、紧凑列表、画册卡片、右侧编辑栏、命名记录统计和“只看问题图片”统一使用同一套重名判定。
- 导出前继续强制拦截同一工程文件夹内的重复文件名；不同工程文件夹中的同名文件不会误报。

### 验证结果

- 自动化测试覆盖同工程重名拦截、重复组识别以及不同工程同名不误报。

## V2.25 - 命名进度持久化与画册模式

更新日期：2026-08-10

更新类型：新增功能 / 本地持久化 / 交互优化 / 响应式适配

### 更新内容

- 命名记录栏新增“保存当前进度”和保存状态，并对命名修改自动防抖保存。
- 新增 IndexedDB `workspace` 和 `files` 存储，恢复全部命名记录、原图、参考图、命名结果、选中状态和每条记录的参数。
- 图片文件首次上传时写入文件库；后续连续改名只更新轻量元数据。
- 重新打开页面时重建对象 URL，并将上次未完成的运行任务恢复为可继续状态。
- 将原组合下拉框拆为“展示模式”和“排序方式”，支持完整列表、紧凑列表和画册模式。
- 画册默认 `4 × 6`、横向 Gap `112px`、纵向 Gap `46px`；支持列数 `1–12`、每页行数 `1–20`、Gap `0–200px`。
- 画册卡片显示原文件名、最终导出名和状态，透明切图使用 `object-fit: contain` 完整展示。
- 宽屏点击卡片后打开右侧编辑栏，小屏改为底部抽屉；修改会同步到列表、卡片和导出文件名。
- 列表/画册模式、Grid/Gap、当前页和选中图片均按命名记录独立保存。
- 将“导出方式 + 导出按钮”收纳为一个紧凑的导出图标菜单，在菜单内选择工程文件夹或 ZIP 并执行导出。
- 将“上传切图文件夹”和“补充上传图片”合并为单一上传入口，点击后再选择文件夹或单张/多张图片。
- 将固定在页面右侧的翻译面板改为紧凑悬浮小窗，可通过标题栏拖动并自动限制在浏览器可视范围内。
- 翻译输入框改为单行单词输入，缩短操作按钮和结果区域；API 设置展开时在小窗内部滚动，不再大面积遮挡命名内容。

### 安全与异常处理

- API Key 仍使用原有设置存储，不复制到命名工作区存档。
- 存档只在同一浏览器和同一工具地址中生效，不上传云端。
- 本地空间不足、数据库不可用或存档损坏时会显示原因，不自动清除已有存档或当前页面数据。
- 删除图片或命名记录时，只清理对应的本地文件，不影响其他记录。

### 验证结果

- Chrome 实测 35 张图片按默认 24 张/页分为两页，宽屏固定右侧编辑栏与窄屏底部抽屉正常。
- 两条命名记及 37 张原图、2 张参考图在刷新后完整恢复，上次运行中的图片正确标记为任务中断。
- 画册修改名称后，39 条图片/参考图文件记录的写入时间均未变化，验证仅更新元数据。
- 删除单张图片和整条记录后，只删除对应的 IndexedDB 文件记录。
- 损坏存档与模拟空间不足均有明确提示，页面数据不会被清空。
- JavaScript 语法检查、Git 差异检查、PowerShell 语法检查和导出回归测试通过。

## V2.24 - 按工程文件夹与 ZIP 可选导出

更新日期：2026-08-06

更新类型：新增功能 / 下载导出优化 / 数据保留

### 更新内容

- 开始命名工具栏新增“导出方式”，可选择“工程文件夹”或“ZIP 压缩包”。
- 工程文件夹模式会在用户选择的保存位置下，自动创建按图片工程名命名的子文件夹。
- 同一批图片包含多个工程名时，会自动分到多个工程文件夹。
- ZIP 模式下载单个按工程名命名的压缩包，压缩包内部仍按工程分目录。
- 浏览器不支持文件夹写入时，不再逐张散落下载，自动回退为 ZIP 压缩包。
- 引入本地固定版本 `fflate 0.8.3` 生成 ZIP，图片压缩过程完全在浏览器本地完成。
- 应用升级时不再清除项目方案、命名规则、API 设置和命名偏好等本地数据。

### 安全影响

- ZIP 只包含当前命名任务中已经上传的图片，不上传网络，不重新编码图片内容。
- 工程文件夹模式只写入用户主动选择的目录，并只创建工程子目录和命名后的图片。
- 第三方压缩组件使用 MIT 许可，并将版本和许可证固定保存在项目内。

### 验证结果

- JavaScript 语法和 Git 差异检查通过。
- 自动化测试确认工程文件夹分组、ZIP 目录结构、图片字节一致性、Windows 保留目录名处理和重复导出名称拦截均正常。
- Chrome 页面检查确认 V2.24、导出方式选择框和本地 ZIP 组件加载正常，未发现运行时脚本错误。
- 当前开发环境为 macOS，Windows 文件夹选择器和资源管理器中的最终表现仍需在 Windows 端确认。

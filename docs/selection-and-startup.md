# 图片删除与开机自启动

- 命名页勾选一张或多张图片后，在窗口底部显示固定批量工具栏；可统一设置前缀名、工程名和界面名，并显示已选数量及删除入口。批量设置只修改勾选图片，保留每张图片原有的最终名称；留空应用工程名或界面名时恢复使用当前默认值。
- 批量工具栏会识别勾选图片的现有值：值相同时直接回显，不一致时显示“多种值”。前缀可从现有前缀库选择，工程名和界面名支持按 Enter 快速应用。
- UI 切图检测页勾选图片后，顶部删除入口滚出视野时，在窗口底部显示固定操作条，显示已选数量并删除选中图片。切换页面或取消选择后隐藏。
- 命名删除优先处理勾选图片，未勾选的编辑中图片不再被一起删除；没有勾选时保留原有删除当前编辑图片行为。
- 检测页新增图片勾选、全选当前筛选列表及删除选中图片。删除仅移出应用列表，不删除磁盘原图。
- 命名记录删除按钮点击区域为 44×44 像素，保留独立的无障碍名称，键盘操作删除按钮不会触发记录切换。
- 设置的「数据与关于」新增开机自启动。首次使用默认关闭，不自动创建启动项。用户开启后通过 Electron 原生接口注册当前用户启动项，登录 Windows 时启动软件，关闭后移除。
- 自启动读取对应名称的 `launchItems`，支持含空格和中文的安装路径，并显示被 Windows 禁用的状态。开发环境不注册启动项。

验证：真实 Electron 长列表多选、批量前缀/工程名/界面名、完整列表/紧凑列表/画册模式、滚动勾选和删除、命名记录按钮边缘点击、检测全选与取消、设置显示；Windows 原生启动项注册/读取/移除使用唯一测试项并在 finally 清理。未执行实际重启或注销。

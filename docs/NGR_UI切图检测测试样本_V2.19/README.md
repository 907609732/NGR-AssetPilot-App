## 人工测试建议

1. 先关闭重复检测，确认分辨率和格式规则。
2. 再打开重复检测低/中/高三个档位，测试重复资源误报情况。
3. 点击“只看问题图片”和“只看警告图片”，确认筛选结果是否符合预期。

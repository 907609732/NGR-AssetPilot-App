# NGR AssetPilot 数据与安全说明

适用版本：**Windows 桌面版 v3.0.24**。以下说明依据该发布标签的实现；旧 Web 版仅作为浏览器兼容模式单独说明。

## 哪些操作会联网

| 功能 | 处理位置与数据范围 |
| --- | --- |
| 本地知识库命名、手动命名、离线翻译、UI 切图检测、基地提单表解析 | 在本机处理，不因这些操作上传文本或图片。 |
| 本地 AI 搜图 | 模型就绪后在本机分析图库和查询；查询图片、搜索文字与搜索历史不持久保存。首次下载模型需要联网，也可导入离线模型包。 |
| 在线文本翻译/文本命名 | 向所选翻译或文本模型服务发送待翻译文本或命名请求；文本翻译不发送切图图片。 |
| AI 视觉命名 | 向用户选择的模型服务发送切图、参考效果图、原文件名及相关命名规则、词库、提示词和项目上下文。 |
| NGR 云翻译 | 通过配置的百度 CFC 服务转发翻译文本；客户端只持有公开 Endpoint，百度服务端密钥保存在 CFC 环境变量中。 |
| TAPD 周报、月报与 Bug 媒体 | 使用专用 Chrome 中的登录会话访问 TAPD，采集有权访问的单据并按用户操作下载媒体；报表与已下载媒体保存在本机。 |
| ArtHub 查询 | 按已配置的服务和连接信息进行只读目录查询；当前客户端定位协议未完成真实验证。 |
| 网络/API 诊断、检查更新、模型下载 | 访问所选或登记的服务、GitHub 发布资源及模型源；本地处理能力不代表整个软件始终不联网。 |
| 图片、ZIP、报表与迁移包导出 | 在本地生成并写入用户选择的位置，不因导出动作上传图片。导出文件需由用户自行管理。 |

联网功能的内容会到达相应服务，使用时应按项目要求选择服务和待处理资料。

## 本机存储与版本身份

桌面版的主数据目录如下：

| 运行身份 | 主数据目录 |
| --- | --- |
| 正式版 | `%APPDATA%\NGR AssetPilot` |
| 开发版 | `%APPDATA%\NGR AssetPilot Dev` |
| 测试版 | `%APPDATA%\NGR AssetPilot Test` |

项目、方案和轻量设置由应用内部的 `localStorage` 保存；命名记录、导入图片与参考图由应用内部的 IndexedDB 保存。它们位于桌面应用的资料范围内，与日常 Chrome/Edge 的站点数据不同。重新打开同一 Windows 用户下的同一版本身份可恢复已有工作区；这不提供云同步，也不代表全部资料均被加密。

API 密钥单独由 Electron `safeStorage` / Windows DPAPI 加密保存。已保存密钥由主进程用于请求，界面读取服务元数据和是否已配置密钥的状态。不要把复制主数据目录视为跨 Windows 用户或跨设备的密钥迁移方式。

本地搜图的索引、模型和缩略图位于主数据目录下的 `local-image-search`。源图库目录只读；移除图库清理应用索引和缓存，不删除磁盘源图。命名或检测列表中移除图片也不等于删除原文件。

**部分集成资料使用独立位置：**

- TAPD 报表数据库位于 `%APPDATA%\TAPD月报工具\reports.sqlite`，专用 Chrome 资料位于同目录的 `tapd-browser`。v3.0.24 正常运行时使用这个历史目录，正式、开发、测试版并非各自独立；其中可能保留登录会话。
- Bug 图片和视频位于用户选择的媒体导出目录；月报 Excel 只嵌入当前报表范围内已提取的图片，视频仍作为媒体文件管理。
- 快速找界面扩展安装在 `%APPDATA%\NGR\extensions\quick-interface-finder`。扩展资料位于对应宿主主数据目录的 `extensions-data\quick-interface-finder`，缓存位于 `extensions-cache\quick-interface-finder`。

## `.ngrap` 备份与旧 Web 版迁移

“数据与关于”中的 `.ngrap` 迁移包保存项目设置、命名工作区、切图和参考图，导入时检查文件清单、路径、大小与哈希。它不等同于整机或整个应用目录备份。

| 数据 | 桌面版新导出的 `.ngrap` |
| --- | --- |
| 设置、命名记录、工作区切图和参考图 | 包含。 |
| Windows 安全存储中的 API 凭据 | **不包含**；新设备需重新配置。 |
| 搜图源图库、模型、向量索引和缩略图 | 独立管理；模型可另用 `.ngrmodel` 离线包。 |
| TAPD 数据库、Chrome 登录资料、Bug 媒体目录 | 独立管理。 |
| 快速找界面扩展安装、模型、项目与缓存 | 独立管理。 |

桌面版禁用了“携带加密凭据”导出选项，但仍可导入旧版含加密凭据的 `.ngrap`，需要原迁移密码；旧凭据块的安全上限为 8 MiB。迁移包中的图片与工作区内容不应被理解为整体密码加密。

浏览器兼容模式将记录和配置保存在同一浏览器、同一工具地址的站点数据内。更换浏览器、改变地址或清除站点数据后，原记录不会自动出现在新环境。该模式的 API 配置不具有 Windows DPAPI 保护；仅在该模式主动勾选携带凭据时，凭据块才用至少 12 位迁移密码加密。

从 Web 版迁移到桌面版，先在原环境导出 `.ngrap`，再在桌面版导入。原浏览器数据不会因导入被自动删除；确认恢复内容完整后再自行处理旧资料。

## 模型、扩展和下载校验

本地搜图的 `.ngrmodel` 会校验版本、文件清单、大小与 SHA-256。自定义 ONNX 模型先在隔离进程中验证，只允许模型与声明的数据文件，不加载脚本或自定义算子 DLL；本地推理阶段关闭远程模型访问。

快速找界面使用单独交付的兼容扩展 ZIP，旧独立 EXE 不能导入。v3.0.24 在首次导入和主动“重新检查”时完整校验；日常打开复用持久校验记录并检查文件元信息，发现变化或记录异常时重新完整校验。因此，日常打开并非每次重读全部扩展文件。

正式安装包从 [GitHub Releases](https://github.com/907609732/NGR-AssetPilot-App/releases) 获取，可与同版 `SHA256SUMS.txt` 比对。v3.0.24 是未签名构建，Windows 的“未知发布者”提示与文件哈希校验是不同事项；哈希校验不能代替发布者签名。

旧仓库中的 Windows 图片预览解除脚本用于清除所选目录内常见图片的 `Zone.Identifier` 网络标记，不属于桌面版安装步骤，也不关闭 Windows 全局安全保护。

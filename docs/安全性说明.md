数据外发范围
本地知识库命名：未发现网络外发，主要在浏览器本地处理。
UI 切图检测：未发现网络外发，图片尺寸和相似检测在浏览器本地完成。
命名进度存档：原图、参考图和命名元数据保存在当前浏览器的 IndexedDB，不上传云端；API Key 不会被复制到命名工作区存档。
存档恢复范围：仅同一浏览器、同一工具地址可恢复；清除站点数据后无法恢复，不提供跨设备同步。
百度翻译 API 命名：会发送原始文件名/命名单词等文本进行文本翻译，不发送图片。
AI 视觉命名：会发送切图图片、参考效果图、原始文件名、当前前缀、词库、匹配规则、项目上下文文档。

图片导出：工程文件夹模式只写入用户主动选择的位置；ZIP 模式使用项目内置的 `fflate 0.8.3` 在浏览器本地打包，不会把图片发送到网络。

Windows 预览解除脚本：只移除用户选择目录中常见图片文件的 `Zone.Identifier` 网络标记，不处理程序、脚本或办公文档，也不关闭 Windows 全局安全保护。

# 快速找界面独立扩展

> 以下为旧版 0.5.6 独立启动器的历史记录。当前源码已改为导入 0.7.0 扩展 ZIP，复用宿主 Electron，不启动独立 EXE 或服务端。使用与验证边界见[扩展工作台说明](./快速找界面扩展工作台.md)。

“更多功能 → 快速找界面”直接启动已绑定的完整便携包；旁边齿轮打开管理弹窗。没有有效绑定时检测本机登记、运行程序、Windows 应用登记及快捷方式、常见解压位置。首次多个候选须选择，已有有效绑定保持不变。自定义目录中从未运行过的旧便携包可能需要“选择已有程序”。下载按钮打开 GitHub Releases，不自动下载或安装。

宿主只包含发现和启动适配，不包含扩展业务代码、运行时、模型和资料。独立源码保留在 `E:/快速找界面/`。扩展由自己的更新器管理；宿主退出不关闭扩展。宿主不删除或迁移扩展目录，也不修改原工作区。

绑定保存在 `%APPDATA%/NGR/extension-bindings/quick-interface-finder.json`；扩展从 0.5.6 源码开始在 `%APPDATA%/NGR/extension-discovery/quick-interface-finder/` 登记发行程序路径。登记只是线索，每次绑定/启动重新校验 ASAR 应用名、实际版本、发行入口、服务端版本和配套 Node/Python。源码 Electron 进程、孤立 EXE 和不完整目录不能自动绑定。宿主测试使用单独绑定目录。

## 每次发布

- 检查 `build/extensions.json` 的已验证版本和日期。扩展没有更新可以沿用，不能将源码版本当作公开发行版本。
- `npm.cmd run extensions:check` 显示版本提醒；三个版本构建均自动检查，联网失败显示“未检查”，不阻止打包。
- 构建输出 `extension-report.json`、`extension-release-notes.md`；构建清单包含扩展版本。CI 将扩展说明附加到正式发布说明及 Actions 摘要，上传上述文件。
- 主软件与扩展独立升级；本机能运行、构建成功或发现新版不代表新版已经完成兼容验收。扩展大文件留在原 GitHub Releases 下载仓库。

## 2026-10-23 验证

旧版 0.5.5 和新版 0.5.6 完整便携包通过真实程序身份校验、冷启动、可见窗口、重复启动复用、宿主退出后保持运行。0.5.6 后端 `/health` 返回正确应用身份及版本，发行包实际生成路径登记。验收采用临时宿主配置和临时扩展资料目录；不改变现有工作区。发行包登记保存在正常发现目录，只包含程序路径和版本，不包含测试资料路径。

主软件全量测试 202 项：201 通过，1 项现有打包条件测试跳过。扩展项目全量测试 39 项通过。新接口、绑定恢复、原生选择校验、启动错误、离线提醒和发布清单检查均已覆盖。公开下载仍指向实际 Releases 页面，本地已验证 0.5.6 不等于该版本已经公开发布。

可重复执行：设置 `NGR_FINDER_TEST_EXE` 为完整便携包内的 EXE，然后运行 `node tests/finder-extension-e2e.mjs`。该脚本使用真实扩展服务与发行 EXE、隔离测试宿主；主界面及 IPC 交互由 `tests/electron-smoke.test.mjs` 验证。仅终止测试自己启动的进程。
